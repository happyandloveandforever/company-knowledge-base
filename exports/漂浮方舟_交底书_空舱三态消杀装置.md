## 第一节 名称与一句话定位

**名称：** 一种排空式高盐漂浮舱的空舱气相处理装置及控制方法

**它管什么：** 人离开、液体抽到储液罐之后，在关严的空舱里处理**舱内壁**；人在舱里时这套氧化不许开。

**它不管什么：** 不主张「漂浮舱采用光触媒/AOP」本身；不主张排空到储液罐本身（那是现有技术 `PAT-PRI-069`）；不写疗效、人体、智能排房。

> ✅ 写够了：这一节不出现疗效、迷走、杀菌率百分比。

---

## 第二节 背景与现有技术

**别人一般怎么做：** 【填：市面上漂浮舱循环过滤 / UV / 臭氧 / 双氧水怎么接；舱壁脏了怎么擦】

**别人的做法在我们这里为什么不够：** 循环只处理流过管路的液体，舱壁上的膜不流经反应器；高盐里羟基自由基活不长，往液体里打臭氧还可能走出溴酸盐路径。这些用公开文献和行业公开资料就能说，不必先做对照实验。

**已知必须绕开、不能当发明点的：**

- 排空到储液罐再回填：US6623632 等（`PAT-PRI-069`）
- 漂浮舱 UV+臭氧+双氧水：行业公开在售（`PAT-PRI-065`）
- 光催化水处理反应器：商品 + 专利（`PAT-PRI-066`）
- 紫外消毒浴缸、臭氧消毒柜、带光触媒涂层的舱体——太宽，会被直接对比

> ❌ 常见错误：把「我们用了光触媒」写成发明点。

## 第三节 要解决的技术问题

**通用描述（可作起点）：** 排空式高盐漂浮舱在占用、空舱、回填三种工况下，若气相氧化与占用重叠，人会被激发光或臭氧伤到；若只做液相循环，舱壁生物膜处理不到；若排空后立即开激发灯，盐霜会盖住催化面；若臭氧接到液体，与可能含溴的泻盐长期共存。

**本机真实遇到的冲突：** 【填：上次壁面/气味/灯误开/结盐，实际发生过什么。没有就写「尚未发生，以下为结构防呆」】

**最想解决的那一个：** 【填：如果只能留一个联锁，留哪一个】

## 第四节 技术方案：结构与相对关系

> 关键不是零件清单，是**谁接谁、何时通、何时断**。

### 4.1 已知前提（不主张）

【填：舱体、储液罐、排空泵/阀、回填泵/阀怎么接。画一张从舱到罐再回来的箭头图，用文字描述也行】

### 4.2 占用信号

【填：怎么知道舱里有人。门磁 / 液位 / 红外 / 其他。没有可靠信号则件1不要递】

### 4.3 舱内表面与激发源

【填：涂层在哪些面；激发源装在哪、朝哪；和人躺下时的眼睛、皮肤是什么相对位置】

【工程师确认：有光催化涂层或明确计划涂】 有 / 无

### 4.4 臭氧流路（没有臭氧机则整小节删掉）

【工程师确认：有臭氧发生器】 有 / 无

【填：发生器出口现在接到哪。目标写法：唯一出口通向空舱气腔；与液路之间有不可旁通的隔断（阀、盲板、物理断管——以实物为准）】

【工程师确认：液相还有没有臭氧接入点】 有 / 无（应为无）

### 4.5 三态互斥

用工程师的话填「进入条件 / 设备动作 / 禁止事项」：

| 状态 | 进入条件 | 设备动作 | 禁止 |
|------|----------|----------|------|
| 占用 | 【填】 | 激发断电；臭氧不向气腔投加 | 空舱处理、回填 |
| 空舱气相处理 | 【填：已排空、门关、占用为假、盐层判据真】 | 激发可通电；臭氧仅入气腔 | 占用、回填 |
| 回填 | 【填：残余臭氧低于预定限】 | 向舱注液 | 激发、向气腔投臭氧 |

任一时刻只准一个状态为真。【填：互斥是继电器硬线、还是控制器里的互锁、还是两者都有。优先写硬线能指到的那一段】

### 4.6 激发通道与占用的硬件互锁（`030`）

【工程师确认：占用为真时激发通道能在硬件上断路】 能 / 不能

【填：断的是哪根线、哪个继电器、是否不依赖软件】

【填：可见光与激发是同一组器件的两个通道，还是两盏灯】

### 4.7 盐霜放行（`029`）

【填：排空后壁面是否结霜、现在怎么冲】

激发前的判据（选实际有的，没有的删）：

- 表面电导：【填：探头在哪；与厂家说明书哪一条预定上限比较】
- 漫反射：【填：波长；预定上限出处】
- 光电流：【填】

不达标则【填：再冲洗 / 再沥干 / 不许开激发】。  
**此处不要写你们自己测出来的杀菌曲线。**

### 4.8 回填前残余臭氧

【工程师确认：有气腔臭氧探头或可加装】 有 / 可加 / 无

预定阈值【填：探头厂家说明书或安全规范的出处，不要编 ppm】

## 第五节 控制逻辑（用步骤写，不要写成软件产品介绍）

1. 占用结束 → 排空 → 【填：冲壁 / 沥干】
2. 读盐层判据 → 不通过则回到冲洗
3. 确认占用为假、门关 → 进入空舱处理：激发通电；若有臭氧则仅向气腔投加
4. 处理结束 → 激发断；分解或等待残余臭氧
5. 残余臭氧低于预定限 → 允许回填
6. 回填完成且占用许可为真 → 才允许下一位进入

【填：每一步失败时机器实际做什么。不要写「智能判断」】

## 第六节 效果怎么写（禁止编实验）

只写**结构上必然发生的事**，例如：

- 占用时激发硬件断路，因此人在舱内时激发通道不能通电
- 臭氧若按 4.4 接线，则不能经该发生器进入液体
- 盐层判据为假时激发不开

不要写：杀菌率、菌落下降几个数量级、比抹布擦更干净、对健康有益。
