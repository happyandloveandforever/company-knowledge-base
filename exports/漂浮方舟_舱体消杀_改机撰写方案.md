# 舱体消杀 · 改机后怎么写（一件）

> 仅内部 · 未公开。不是正式法律意见。权要由代理师定稿。  
> 余光件仍然暂停。现机结论仍成立：不改机就没有独立件。  
> 本篇只在「愿意改机器」的前提下写。不编杀菌率、不测壁面刮菌。  
> 对照：`PAT-IDEA-028` / `029` / `030`；现机纪要 `工程师确认-空舱现状与改判.md`。

## 一句话

**只写 1 件。** 名称建议：一种带分态通气孔的排空式漂浮舱空舱气相处理装置。

独权不要落在「用了光触媒」「用了臭氧」「会冲舱」。落在三件事绑在一起：

1. **占用时通气孔必须开**（人要呼吸），空舱气相处理时通气孔必须关或切过滤（处理剂不能漏到舱外）。  
2. **臭氧只进空舱气腔**，液路物理断开（现机是接到液体，这是要改的）。  
3. **占用 / 空舱气相处理 / 回填许可** 三态互斥；占用时紫外/激发硬件断电；回填前气腔臭氧低于预定阈。

冲洗舱壁仍然做（现机已有），但不主张「会冲」；只主张 **冲完才允许激发**。涂层余辉、暗适应、时变余光都不写。

适合发明 + 实用新型同日。

交底书：`patent-drafts/交底书-空舱气相消杀-改机.md`

## 现机保留什么、必须改什么

| 现机 | 改机后 | 为什么改 |
|---|---|---|
| 关门 + 通气孔常开 | 通气孔做成可切换：占用开、空舱处理关（或切过滤） | 有孔就不是封闭气腔；不切换，臭氧会漏到舱外 |
| 臭氧接到液体 | 唯一出口通向空舱气腔，液路盲断 | 现接法是行业标配，不能主张；改接才是流路发明点 |
| 无光催化涂层 | 空舱激发能照到的内壁加涂层 | 没有涂层，空舱紫外就是杀菌灯 |
| 无臭氧探头 | 气腔加探头，低于厂家预定限才许回填/开门/开孔 | 没有这道门，气相臭氧写不完整 |
| 舱内紫外灯 | 保留；占用时 **硬件断电**；空舱处理时作为激发源 | 人在时不能被照到 |
| 排空后自来水冲壁 | 保留；冲完才允许激发 | 冲壁本身已公开；闭环是「不冲完不开灯」 |
| 冲水不结盐 | 如实写。不要编盐霜曲线 | `029` 收成冲洗放行，不写「盐霜盖死涂层」当已证事实 |

不改的：排空到罐本身（现有技术，写进前序）。余光、迷走、40Hz、杀菌率。

## 三态（必须写进说明书）

**占用**  
门关；通气孔开；紫外/激发硬件断；臭氧发生器不对气腔供气；不回填。

**空舱气相处理**  
已排空；占用为假；门关；通气孔关（或过滤）；壁面已冲洗；激发通电；臭氧仅入气腔。禁止占用、禁止回填。

**回填许可**  
气腔臭氧低于预定限；激发断；停止向气腔供臭氧；通气孔可再开；才允许回填。任一时刻只准一个状态为真。

这不是「封闭消毒柜」。封闭消毒柜没有「占用时必须开孔呼吸」这一条。你们的孔是产品事实，改机是让孔 **分态**，不是把孔焊死。

## 不要写进独权

- 排空、冲舱、紫外消毒、光触媒本身、臭氧本身  
- 「杀菌更干净」、壁面菌落下降（没做对照）  
- 溴酸盐下降（没测溴；液相禁臭氧只写流路，不写副产物效果）  
- `026` 窄间隙（要测清除速率）  
- `031` 五项合取（缺数）  
- 余光、暗适应、挡光迷宫（用户已否）  
- 把通气孔焊死当封闭气腔（与「人要呼吸」矛盾，审查会对不上现机事实）

## 改机零件清单（交底书里逐项勾「做」）

1. 内壁光催化涂层（哪些面，必须写）  
2. 臭氧管：切断进液口，只留进气腔，中间不可旁通  
3. 通气孔执行器：占用强制开，空舱处理强制关或切过滤  
4. 气腔臭氧探头  
5. 占用信号（门磁/液位/红外，现机还没说）  
6. 紫外/激发占用时硬件断电  
7. （可选）冲洗废水不回储液罐  

1–6 缺一项，本件不要递。7 不影响立案，有则当从权。

## 公开充分怎么过（仍然不测）
