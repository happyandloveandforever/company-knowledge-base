## 一、这本手册在公司文件里的位置

旧稿把「科学史、功效病谱、合作项目、禁忌、流程」订成一本，对外口径、证据级别、门店执行搅在一起。知识库已经把这三件事拆开了，新手册不要再混回去。

| 文件 | 读者 | 负责什么 | 不负责什么 |
|------|------|----------|------------|
| **漂浮知识手册（本文件）** | 全员查阅 | 漂浮是什么、科学到哪一步、对外怎么讲、接待底线 | 不是开舱清单，不是设备说明书 |
| 开业 SOP（`KP-SOP-*`） | 门店 | 动线、水质、话术、转化 | 不是文献综述 |
| 漂浮师培训大纲（`KP-TRN-*`） | 内训 | 学习目标、误区、考核 | **禁止外发** |
| 产品使用手册（`KP-MAN-*`） | 运维 | 点点控、呼叫器、维保 | 不含功效宣称 |
| 机理一页纸（`KP-MECH-*`） | 学术/B 端 | 减负—降噪—重置—整合 | 不讲产品报价 |

**新手册的身份：** 内部知识手册，正文按「流出也不构成医疗宣称」来写。学术专名 REST（Restricted Environmental Stimulation Therapy）可以出现在引用里；对客统一用「深度恢复 / 神经重置 / 调节」，不用「治病、治愈、处方、适应症清单」。

## 二、旧稿哪里能留，哪里必须改

### 留（骨架是对的）

1. **封面定位「内部使用」** — 继续。加一句：纸质编号发放，不发原件给客户、加盟商、合作方。
2. **愿景页** — 可留，句子收短。
3. **胡佩诚前言** — 作为中国落地史料整篇保留，但加编者按：前言是口述史，不是现行销售口径；其中静脉注射硫酸镁、成绩提高几十分、把漂浮写成最高层次治疗，**不进入后文主张**。
4. **「什么是漂浮」定义句** — 方向对，改成知识库的 REST 九通道操作定义（`KP-WEB-007`）。
5. **历史章**（感官剥夺 → Lilly → Suedfeld REST → 干/湿漂 → 中国 1997）— 这是旧稿最好的部分，清洗笔误后作为通识正文。
6. **「死海 / 游乐园不算漂浮」** — 必须留。这是把品类和泡澡分开的关键句。
7. **如何漂浮的八步示意** — 留结构，按 SOP 补：问卷、呼叫器、姿势、出舱防摔、红旗、卫生。

### 改（旧稿的硬伤）

旧稿「效果概述」和「前沿项目」把抑郁、成瘾、哮喘、肥胖、脑卒中、不孕、产后抑郁、高血压、青少年成绩、儿童增高写成了产品功效。这和知识库红线直接冲突（`KP-TRN-069`、`KP-MEV-102`、`KP-WEB-010`、`KP-SOP-009`）。

| 旧稿写法 | 知识库裁定 | 新稿处理 |
|----------|------------|----------|
| 漂浮疗法可改善抑郁/焦虑/成瘾/强迫/进食障碍 | 禁止写成适应症 | 改成「文献在追问的信号」；销售菜单只保留压力、睡眠管理、主观恢复 |
| 专利超饱和富氢漂浮液排除体内垃圾、代谢紊乱康复 | 富氢数字待锁；排毒叙事对外禁用 | 删「排毒/排垃圾」；氢、光、AI 功效不覆盖进 REST 文献 |
| 镁离子抑制心肌、降心血管死亡 | 透皮补镁证据不足（`KP-WEB-005`） | 镁盐只讲浮力与皮肤接触，不讲输液式补镁 |
| 加快排出乳酸 | 文献不一致（`KP-WEB-006` / `KP-TRN-070`） | 对外只锁定主观疲劳与恢复感受 |
| 海马体灰质增多、杏仁核减小 | 旧稿未给可核验出处 | 删。不编神经解剖疗效 |
| 天伦医院不孕 50 例近半有效 | 未发表、非 RCT | 降为「合作观察线索，不对外引用」 |
| 产后抑郁项目 | 方法有（ACT+漂浮），结果未给出 | 降为线索；不写治愈产后抑郁 |
| 高血压总有效率 69% | 可对应胡佩诚 2000 小样本观察，n 约 30 | 可作历史文献一句；不作产品有效率 |
| 成绩提高几十分；12 岁前漂 10 次增高 3–5 cm | 无核验、有医疗风险 | **整段删除**，列入停用清单 |
| Feinstein 写成「手段最严格」暗示已证明治疗价值 | 2018 是开放标签，不是 RCT（`KP-WEB-001`） | 纠正设计标签，补 Garland 2024 可行性 RCT |
| 禁忌：6 岁以下、1–4 月及 7 月以上孕妇、70 岁以上 | 与 SOP 不完全一致 | 取更严：按 `KP-SOP-023`（孕 1–3 月或 ≥8 月拒；0–6 岁拒；6–15 岁与 65+ 须评估） |
| 比重约 1.128 | SOP 验收 1.23–1.26（`KP-SOP-015`） | 门店执行以 SOP 为准；1.128 不采用 |
| 液温与体温一致 / Lilly 34.6℃ / 教材 37–39℃ / SOP 36±0.5℃ / 话术 38℃ | 已挂账待老板锁（`KP-TRN-070`） | 正文写冲突，执行写「独立门店按 SOP」 |

### 补（旧稿缺、知识库已有）

1. **证据金字塔**：先安全可行，再即时状态，再病种 RCT（`KP-WEB-010`）。
2. **2025 / 2026 综述**：痛、压力、焦虑有信号；睡眠与戒烟弱；慢性痛还不能做元分析定论（`KP-COM-014`、`KP-COM-015`）。
3. **政策一句**：主动健康的心理与睡眠支柱，不是基本公卫、不是医保（`KP-WEB-008/009`、`KP-COM-007/008`）。
4. **卫生**：UV/臭氧是国际浮舱主流，不靠泳池氯方案恐吓（`KP-WEB-004/012`）。
5. **舱内红旗**：出舱，不解释排毒（`KP-SOP-024`）。
6. **口径对照表**：从培训总纲抽一页进手册，让销售和漂浮师共用（`KP-TRN-069`）。
7. **待锁定数字**：机构数、专利、C 端量、水温、58%/2000 项研究——统一「以合同/铭牌为准」（`KP-COM-004`）。
