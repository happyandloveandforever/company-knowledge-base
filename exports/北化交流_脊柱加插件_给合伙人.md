# 北化第一次交流 v2：脊柱 + 插件（给合伙人）

> 内部文件。北京化工集团第一次接触，想了解项目，如果可以有投资意向。  
> 合伙人口径：**让对方了解我们，知道方向和他们的需求一致就行。**

## 为什么不再给你五套完整方案

上一版的 A–E 不在同一个维度：A 初识、E 样板讲的是「谈到哪一步」，B 工业品、C 政策、D 国际讲的是「用谁的语言」。
两个维度混在一张表里，所以会想拼「A 加半页消杀」。

这版把阶段写死——**第一次见面就是介绍**——只让语言当变量：

- **脊柱**：9 页，固定，谁到场都讲
- **插件**：半页到一页，按谁到场加

合伙人要做的事从「选一整套」变成「勾两三个半页」。

## 散场标准（先定这个，再定页数）

1. **听懂我们是什么**：可复制的深度恢复系统，不是 SPA、不是理疗店
2. **知道方向**：主动健康 / 非药物恢复，和他们的产业与人力议题挨得上
3. **愿意再谈**：觉得值得下一步，但本场不谈钱、不谈估值

投资不在这三条里。同路了他们自己会问。

## 脊柱（9 页 / 约 15 分钟）

| # | 页 | 讲法 |
|---|----|------|
| 1 | 一句话我们是谁 | 可复制的深度恢复系统 |
| 2 | 为什么是现在 | 从治病到主动健康，非药物恢复缺入口 |
| 3 | 方法一页 | 减负—降噪—重置，不堆模块名词 |
| 4 | 一次体验里发生什么 | 让他们脑子里有画面，60–90 分钟 |
| 5 | 我们已经在做的事 | 只讲能公开的，数字标口径或不写 |
| 6 | 边界写清楚 | 不治病、不替代医疗、不做承诺 |
| 7 | 和北化的三个可能接口 | 企业精力 / 园区示范 / 产业布局 |
| 8 | 入口很轻 | 参观或一次小体验，不用先决策 |
| 9 | 下一步一句话 | 只请他们同意一件小事 |

## 插件菜单

### P1 工程可巡检（1 页）

**触发：** 席上有工程、质量、安全、生产口的人

**加什么**
- 三分体结构与消杀闭环
- 水温、水质、记录：谁测、多久测一次
- 一句话：这是能连续运行的设备，不是网红体验

**为什么加：** 化工的人信过程和记录，不信形容词。这页把我们从「概念」拉到「可巡检」。  
**风险：** 讲太细会变工厂参观，压到 1 页，不展开台账。

### P2 政策与人力口（1 页）

**触发：** 规划、党委、工会、HR、园区主导这次会

**加什么**
- 治病中心 → 健康中心，我们补心理与睡眠这一格
- 企业过载：讲座解决不了，需要可体验入口
- 明确不是医保、不是治病

**为什么加：** 让这件事能被写进他们自己的规划和员工议题，而不是只当一个供应商。  
**风险：** 只讲政策会显空，必须紧跟脊柱的方法页，别单独放。

### P3 底气半页（0.5 页）

**触发：** 担心被当成小作坊；对方级别高、看惯大场面

**加什么**
- 平台与冠军产品线、认证与消杀能力
- 专家与合作生态各一行
- 规模数字标「材料口径」，未锁的不写死

**为什么加：** 压住「你们多大」这个问题，但不把它做成路演封面。  
**风险：** 一旦写具体机构数、用户数、专利数，追问就被动。宁少写。

### P4 证据塔（0.5 页）

**触发：** 席上有医学、科研、医院背景的人

**加什么**
- 塔基安全与可重复 → 塔身即时状态改善
- 国际研究说到哪一步，如实说：多为小样本、可行性
- 塔尖病种效果不进主页

**为什么加：** 懂行的人在场，先示弱反而更可信；把边界自己说出来，别等他们挑。  
**风险：** 别把病种 RCT 当卖点；乳酸这类争议只讲主观恢复。

### P5 落地一页（1 页（只在对方先问时打开））

**触发：** 对方主动问「怎么合作、落哪个点、怎么投」

**加什么**
- 一个点位、一个季度、可退出
- 三选一：企业精力 / 园区示范 / 康养旗舰
- 采购 / 联营 / 样板，各一行，不报价

**为什么加：** 把「想投资」软着陆成「先试一个点」，比谈估值安全得多。  
**风险：** 不要主动翻这页。没人问就留在附录，否则像默认他们要买。


## 常见席位，直接照抄

| 对方来了谁 | 配置 | 为什么 |
|------------|------|--------|
| 只来了战略投资口 | 脊柱 + P3 | 他们要判断你有多大、值不值得再谈 |
| 带了工程或安全 | 脊柱 + P1 | 有人会问怎么消杀、怎么保证不出事 |
| 规划 / 党委 / HR 主导 | 脊柱 + P2 | 他们要能把这件事写进自己的口径 |
| 有医学背景在场 | 脊柱 + P4 | 先自己划边界，比被追问好 |
| 对方开场就问合作 | 脊柱 + P5 | 顺着他们走，但只到一个可退出试点 |
| 一大桌人都来了 | 脊柱 + P1 + P2 | 其余全部进附录，现场按提问再翻 |

## 四条红线（任何配置都不许破）

- 不讲治病、不讲病种有效率、不提医保与科室话术
- 机构数 / 专利数 / C 端用户：标「材料口径」或不写
- 医院联合运营稿与独立门店 SOP 两套口径，不混在一页
- 本场不出估值、不出财务模型、不主动提融资金额

## 推荐

**脊柱 9 页 + P3 底气半页，合计约 10 页 / 20 分钟。**

第一次来了解，最可能出席的是战略投资口，他们心里的问题是「你们多大、值不值得再谈」。
P3 用半页回答，且不写死数字。其余插件带在附录，现场按提问翻。
