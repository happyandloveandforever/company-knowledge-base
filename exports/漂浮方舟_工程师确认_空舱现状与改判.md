# 工程师确认纪要 · 空舱现状过闸（2026-09-06）

> 仅内部 · 未公开。不是正式法律意见。  
> 来源：用户当面确认。未确认的仍标【缺】，不编。

## 已确认的现状

| 原件1 需要的前提 | 现状 | 对原件1的影响 |
|---|---|---|
| 空舱关门形成**封闭气腔** | 要关门，但**肯定有通气孔**（人躺着要呼吸） | 不是封闭气腔。空舱打臭氧会从通气孔漏到舱外，不能按 `028` 写 |
| 臭氧出口只通向气腔 | **臭氧机出口接到液体** | 与 `027`/`028` 主张的方向相反。接液体是行业公开做法（`PAT-PRI-065`、US9956374），不能当发明点 |
| 内壁光催化涂层 | **目前没有** | `028`/`029`/`042` 的涂层前提不成立 |
| 盐霜盖住催化面 | **排空后自来水冲一下就不结盐** | `029` 的高盐独有失效，这台机器上没出现 |
| 回填前残余臭氧探头 | **没有** | 不能写「臭氧低于预定阈才回填」 |
| 舱内激发/紫外 | **舱内配有紫外灯管** | 这是现状里最硬的光学硬件，转去件2 |

另已确认：**占用时要关舱门。** 排空后会冲水（会排空）。储液罐是否外置、占用信号从哪来，仍【缺】。

## 过闸结论

**原件1（空舱气相光催化 + 臭氧仅入气腔 + 盐霜放行 + 臭氧探头回填）按现状不能递。**

硬写会变成说明书里的一台你们没有的机器：封闭气腔、壁面涂层、臭氧改接到气、回填前探头，四件都没有。

去环境测试也过不了：没有涂层、冲水不结盐，拿掉高盐只剩「空舱开紫外灯」，就是普通紫外消毒柜/浴缸，`028` 正文自己写了不要这么写。

臭氧继续接液体：不要写 `027`（液相禁臭氧），那是改机方案，而且与现机相反。

## 改判后只写一件

把真实冲突写进原件2，作为**现在的第一件**：

**关门 + 通气孔要呼吸 + 舱内有紫外灯 + 占用时要足够暗。**

通气孔既是气道也是漏光路径。紫外灯既是空舱处理手段，也是占用态最强的可见/近紫外残余源。不要求封闭、不要求涂层、不要求臭氧探头、不要求先测漏光地图（不写 `043` 的可寻址阵列）。

交底书：`patent-drafts/交底书-时变余光限制装置.md`（已按现状改写）。  
原件1交底书保留，封面标明「按现状不递」，避免以后有人再按旧菜单开写。

## 件2 还缺的是非题（下一轮只要这几条）

1. 占用时舱内紫外灯管能不能**硬件断电**（不是只靠软件关）？
2. 「舱里有人」现在靠什么：门磁、液位、红外、还是没有？
3. 通气孔大概在哪：头顶、脚端、舱顶、舱门周边？几个？
4. 除了紫外灯，占用时还有没有指示灯、触摸屏、舱缝漏进来的光？
5. 有没有近红外摄像头？没有也可以写，保护会窄一些。
6. 通气孔愿不愿意做成**挡光气道**（弯头/迷宫，风能过、直视光线过不去）？这是改进结构，不是现机上已经有的零件。做，才有比较像样的结构特征；不做，本件只剩「占用关紫外 + 时变上限」，创造性会薄。
