## 一、为什么要出 v3.0

v2.0 做对了三件大事：查实绝对新颖性、把门从「去盐」改成「去环境」、把母案 B 从通用安全控制收窄。然后它留下一句现在已经过时的话——「盐雾致盲是唯一确认的缝」。

v2.0 之后又做了四轮过闸：

1. **三个绿灯角度补检索** → 角度①打掉（环境安静是便宜，不是技术问题）。
2. **角度⑤配液检索** → 独立立案打掉；冷管结晶并入母案 A。
3. **NSF/ANSI 50 与氯溴文** → 强制项和「不用氯」不能主张；打开⑦～⑪黄灯。
4. **Codex 独立评审** → 点名专利全部检索入库；**盐堵过滤器 + 识别堵塞的宽方案被海上/防爆气体探测器专利包围**；打开紧急离舱与冷凝分流⑫～⑮。

给人看的一页菜单：`patent-drafts/最终专利方案.md`。配套卡：`PAT-MAP-003`、`PAT-EXT-002`。

### 本版三条核心结论

1. **现在没有一件可以负责任地标成「高信心、马上提交」的大母专利。** 独立评审同意这一点。
2. **主线仍是多开撰写思路，交给专利专家和技术专家选。** 过闸是为了别把标准、公知、「环境更有利」当成发明，不是把清单收成只剩实验。
3. **架构不要改名。** 仍只立母案 A（高盐多物理场稳定化）与母案 B（高盐环境下的测量可信度）。紧急离舱、冷凝分流是挂上去的撰写候选，专家选了再升成独立件。不设母案 3。

说明书不要再写「高盐蒸汽」。硫酸镁不随水蒸气挥发；盐靠液滴、气溶胶、飞溅、毛细再干燥走。

## 二、仍然有效、不要再推一遍的规则

| 卡 | 规则 | 一句话 |
|---|---|---|
| `PAT-RULE-002` | 绝对新颖性 | 判断标准是**公开**不是授权；国外公开即挡死中国申请。专利权有地域性，国外授权挡不住境内生产。检索必须中外并行，且含 IEC／GB／手册／规范 |
| `PAT-RULE-003` | 去环境测试 | 逐个拿掉 E1—E6。六条全拿掉都成立 → 不立案。**再问：这条环境给的是难题还是便宜？给便宜的不能立案** |
| `PAT-RULE-004` | 第 25 条 | 诊断治疗方法与科学发现不授权，**装置可以** |
| `PAT-RULE-005` | 组合发明 | 被组合技术已知不影响创造性，但必须证明协同；组合专利 ≠ 可自由实施 |
| `PAT-RED-001` | 表达红线 | 不写疗效、迷走激活当目的、人体信号→AI→策略库、姿态调盐度 |

环境指纹：E1 高盐 22—30% MgSO₄ · E2 中性浮力 · E3 感官剥夺 · E4 热中性浸液 · E5 长时程静止 45—90 min · E6 密闭门锁。

抵触申请含自家在先申请 → **母案 A 与 B 必须同日提交**，子案不得抢在母案前。

## 四、第一件底稿：A4 已收窄

文件：`patent-drafts/申请文件底稿-多气源安全互锁.md`。状态卡：`PAT-DRAFT-A4`。

v2.0 原定四个发明点，三个早已被公知打掉。当时留下的第四条——「盐堵通气口造成沉默失效」——**本轮被直接前案包围**：

| 公开号 | 写了什么 | 卡 |
|---|---|---|
| US10041917B2 | 海上盐沉积堵烧结滤网 → 假阴性／不报警 | `PAT-PRI-043` |
| US10495620B2 / EP3859317 | 压力传递函数检测保护滤网堵塞 | 同上 |
| US10900942B2 | 测试气脉冲看膜／毛细管受限 | 同上 |

手册写自诊断不覆盖透气孔，只说明**电子自检不够**，不能证明「检测堵塞」没人做过。

**还可能写的只有窄缝：** 与传感器同朝向、同暴露路径的可替换见证件，在电路自检仍正常时更早反映硫酸镁沉积。须对照实验。没有实验，不按宽概念申报。

先问工程师：会不会同时装氢气与臭氧。若不会，底稿前提仍不成立，改写 A3。

## 九、实验与采访（替代不了检索，检索也替代不了实验）

每一项都要有清水（或无盐高湿）对照。

| 优先 | 做什么 | 决定什么 |
|---|---|---|
| 1 | **见证件对照**：高盐 vs 清水 vs 无盐高湿；电路自检仍正常时，见证件能不能更早反映扩散受限 | A4 窄缝生死 |
| 2 | **角度③**：气泡开／关各测一次舱内声压 | 差很小则③不成立 |
| 3 | **⑫ 样机**：无机构／固定扶手／转换机构，不同漂移位置起身 | 紧急离舱写不写得成 |
| 4 | **⑭ 淡层**：实际舱有没有稳定淡层 | 没有就停 |
| 5 | 问工程师：是否同时装氢气与臭氧 | 底稿前提 |

采访仍用 `PAT-WRITE-004` 和 `patent-drafts/交底书-母案A.md`。工程师没说过的结构、参数、阈值一律不写。

## 十、建议专家怎么选（不是结论）

1. 样机优先看 **⑫**。人在中性浮力下起不来，是看得见的结构问题。
2. **⑬ 跟⑫一起看**，不要写成一键开门。
3. **③ 仍是测量类最有希望的**，先做气泡开关声压。
4. **⑭ 先做淡层实验**。⑮信心低，没有额外预测价值就放下。
5. 若只能给 A4 加一条从权：看 **⑦ 双指标门控**（水合格不能代替气合格）。
6. 不要主张：不用氯、NSF 强制项、FIFRA、疗效、迷走激活当目的。
