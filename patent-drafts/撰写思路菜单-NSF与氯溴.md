# 撰写思路菜单：NSF/ANSI 50 与氯溴文能开什么、不能开什么

> **2026-09-04 注：** 独立评审后，盐堵通气口**宽方案已不能当确认站得住的独权**。总菜单改看 [`最终专利方案.md`](./最终专利方案.md)。本文件 ⑦～⑪ 黄灯仍然有效；下表「沉默失效」一行已改判。

---

## 先记住三句话

1. **标准里写死的，不是发明。** NSF/ANSI/CAN 50-2021 第 28 节和 CCS-12804 已经把过滤、周转、双吸入口、泵—投加联锁、水中臭氧上限、用户间清洗后余氯 +2 ppm、UV 3-log 写成强制项。US9956374 还写过漂浮舱 UV+臭氧+溶解臭氧监测。
2. **业界共识也不是发明。** FTA《北美漂浮舱标准》公开写：不要用氯/溴当主消杀；CDC 写过氯溴未针对漂浮舱做 EPA 注册。主张「我们不用氯」过不了闸。
3. **法规和人体伤害不能写进独权。** FIFRA 超标签是法律问题；结膜炎、溴疹、支气管痉挛、破坏感官剥夺，踩第 25 条和红线。这些最多当背景里的工程问题（头空间卤素 ppm、材料腐蚀速率）。

过完这三道，剩下的才是菜单。

---

## 不要写进权利要求的（已打掉 / 勿主张）

| 不要主张 | 为什么 |
|---|---|
| 浊度削减 ≥70%、周转 ≤30 min、清洁介质 5 分钟一周转 | NSF 强制测试 |
| 吸入口 ≥2、撇污/溢流、水深 ≤24 英寸 | NSF 强制结构 |
| 臭氧机与循环泵电气联锁 | NSF + 华盛顿州规范，库里已有 |
| 水中臭氧 ≤0.1 ppm | NSF Annex H 强制；且测的是**水里** |
| 用户间清洗后游离氯 +2.0 ppm（或溴 +4.0） | NSF 给投加器的Sizing要求 |
| UV/臭氧/铜银作辅助消毒、3-log 细菌/隐孢子虫 | NSF 强制配置 + 测试协议 |
| 漂浮舱 + UV + 臭氧 + 溶解臭氧监测 | US9956374 |
| 「我们不用氯/溴，改用 UV+臭氧+双氧水」 | FTA 公开共识；NSF 本来就允许「EPA 注册药剂 **或** NSF 50 消毒系统」 |
| FIFRA 超标签 / 地方卫生局冲突 | 法律与行政，不是技术方案 |
| 结膜炎、溴疹、化学性支气管痉挛、刺鼻破坏 REST | 疗效/伤害人体；感官剥夺是红线 |
| 「我们发现盐会把臭氧赶出水面」 | Rischbieter 2000 已测过臭氧在硫酸镁溶液里的溶解度，属科学发现 |
| 「我们发现高盐里 DPD 测不准余氯」 | NSF 2015 实验室报告 + BCIT 已发表校正系数 0.79 |
| 把液相臭氧补偿和头空间盐晶堵孔捆成一套模型 | 两条测量链，见 `PAT-EXT-001` |

卤素 + 高盐腐蚀 316L / 密封件：真实工程问题，但太像材料选型，**不独立立案**，需要时作母案 A1 从权。

## 请专家挑选的撰写候选（全部黄灯 + 待检索/待验证）

灯色含义：🟢 目前最有希望（本批没有新的绿灯） · 🟡 可以写成交底书草稿让专家选 · 🔴 不要投入。

### 候选⑦ 液相达标 ≠ 气相安全（盐析只当背景，不当发明点）

- **卡号**：`PAT-IDEA-007`　挂母案 A4
- **灯**：🟡　信心：中偏低
- **一句话**：NSF 只卡**水里**臭氧 0.1 ppm。高盐会降低气体溶解度（教科书，不能主张发现了它）。同样投加量，小气室（E6）里空气浓度可能更高。装置可以同时看水里和头空间，盐浓度参与投加/排气，水合格但气不合格就不许进人。
- **去环境测试**：拿掉 E1，盐析变弱；拿掉 E6，开敞泳池气室巨大，积聚不成问题。两条都像必要条件。但「面部高度测臭氧」华盛顿州已经要求过，手段层挤。
- **不要写成**：我们发现盐析；我们测头空间臭氧（规范已有）。
- **待验证**：22–30% MgSO₄、34.5–35.5℃、真实头空间体积下，水中 0.1 ppm 时空气浓度相对清水对照组差多少。
- **待检索**：按电导率/盐度调节臭氧投加或吹脱的水处理专利。

### 候选⑧ 客用态 / 维护态两套化学，且液相门和气相门分开

- **卡号**：`PAT-IDEA-008`　挂母案 A4 / B5
- **灯**：🟡　信心：中
- **一句话**：NSF Annex H **关掉氯溴和双氧水**只测辅助系统，等于标准自己承认「可以不加卤素就完成消杀测试」。客用时舱门关、人躺 45–90 分钟，FTA 不推荐卤素，因为头空间会积挥发物。维护态（无人、门开或强排）才允许地方卫生局要的冲击加氯。装置按占用/门锁切换允许的氧化剂集合，并且**水合格不能代替气合格**。
- **去环境测试**：拿掉 E5/E6，普通 spa 冲击加氯也能做。难的是「人在密闭小气室里长时间仰卧」。
- **不要写成**：不用氯本身；门禁排气联锁（已打掉）；泵停则停药（NSF 强制）。
- **待检索**：spa/池「客间冲击加氯 + 占用互锁」；酒店浴缸占用态禁投药。
- **和⑦的分工**：⑦ 是盐浓度改变气液分配；⑧ 是两套配方 + 双门控。不要捆成一个独权。

### 候选⑨ 高密度液上的过滤 / 周转失配

- **卡号**：`PAT-IDEA-009`　挂母案 A1
- **灯**：🟡　信心：中偏低
- **一句话**：NSF 浊度考的是硅粉颗粒，5 分钟周转按清洁滤料、接近清水泵曲线来写。22–30% 硫酸镁密度和粘度都高，盐晶还会让滤料板结。清水过了 NSF，高盐工况下流量、压损、滤后浊度可能对不上铭牌。
- **去环境测试**：拿掉 E1 就变回普通 spa 过滤，题目消失。E1 是必要条件。但化工卤水过滤、反洗、压差控制很成熟，容易被说成「把泵选大一点」。
- **不要写成**：过滤更细、浊度削减方法、周转更快（都是标准项）。
- **待验证**：同一套泵滤，清水 vs 工作比重液的流量—扬程、压差爬升、滤料板结。
- **倾向**：更像 A1 从权，不独立成件。仍留给专家选。

### 候选⑩ 近中性浮力浅舱里的吸入口力平衡

- **卡号**：`PAT-IDEA-010`　挂母案 A2
- **灯**：🟡　信心：低
- **一句话**：NSF 要求 ≥2 个吸入口、按 APSP-16 测卡吸，这是从泳池抄来的。漂浮舱水深 ≤24 英寸，人几乎不压舱底（E2）。卡吸的力平衡和「儿童趴在泳池排水口上」不是一回事。
- **去环境测试**：E2 像必要条件；但双吸入口本身是强制项，不能主张「我们做了两个口」。
- **待检索**：APSP-16 / VGB 在浅水、低体重载荷、高密度液体下的测试假设。
- **倾向**：专家很可能很快打掉。放进菜单是为了让人看见这条缝，而不是默认要写。

### 候选⑪ NSF 要求用户间余氯 +2 ppm，但高盐里现场方法测不准

- **卡号**：`PAT-IDEA-011`　挂母案 B（与第三方角度 E 近，不要和 A4 气相沉默失效混）
- **灯**：🟡　信心：低到中
- **一句话**：NSF 给投加器的指标是用户间清洗后 FAC +2.0 ppm。NSF 自己 2015 年就测过：硫酸镁溶液里多数氯试剂盒不准；BCIT 还发表过 0.79 校正系数。地方卫生局仍可能按泳池方法抽检。装置如果仍要满足这条标准，需要一条**不依赖失效 DPD** 的在线链，并且只用于液体消毒剂量，不用于头空间。
- **不要写成**：我们发现 DPD 失灵（已公开）；电子传感器按温度/pH/电导率补偿（仪表常规，见 `PAT-PRI-040`）。
- **待检索**：近饱和硫酸镁里，海水型余氯/臭氧电极是否仍超额定电导率；失效模式能不能用现成补偿解释。没有对照，不能升绿灯。
- **和 E 的关系**：同一条缝，不要再立第三套「补偿算法」母案。

## 建议专家怎么选（不是结论）

1. 若只能加一条从权到 A4：优先看 **⑦ 的双指标门控**（水 NSF + 气安全，盐浓度只作输入），前提是对照实验做出来。
2. 若地方卫生局强制要氯：看 **⑧ 的维护态冲击 / 客用态禁卤素**，必须先检索 spa 占用互锁。
3. ⑨⑩默认当从权或备选，不单独立项，除非工程师拿出清水对照数据。
4. ⑪继续跟角度 E 同一条检索清单，不新开母案。

实验仍替代不了检索，检索也替代不了实验。本文件不构成正式法律意见。
