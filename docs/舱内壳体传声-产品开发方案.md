# 舱内壳体传声：产品开发方案

内部工程文件｜2026-09-05  
给：结构 / 电气 / 点点控 / 内容 / 验收，用来把功能做到 FA-D、FA-O 上。

本功能不是新发明。Dreampod、i-sopod、Ocean Float Rooms 已经在卖。我们要做的是：**在现有三分体舱上补上这条体验，并且用测量证明人戴着耳塞真的听得见、身体轻轻感到、液面不起波、深静音模式仍然在。**

对外不讲疗效。对内不把「细胞共振 / 迷走 / 40 Hz」当设计目标。

---

## 1. 要做的产品是什么

### 现在缺什么

主机正面已有音乐控制器（32G、可连手机，点点控里叫「音乐舒缓系统」）。那是**空气里的喇叭**。漂浮时客人几乎都戴耳塞，气导被堵住，漂中基本听不见。SOP 里那句「音频振动」，目前没有对应硬件。

### 要交付什么

在舱体外侧（干侧、不碰盐液）装两只全频触觉换能器，把舱壁当成喇叭盆。液体把振动送到全身和颅骨。点点控增加三档，默认关：

| 档 | 名字（对内） | 客人得到什么 |
|---|---|---|
| 0 | 深静音 | 和现在一样，换能器断电 |
| 1 | 引导 | 戴耳塞仍能听见缓慢引导词，身体有很轻的嗡 |
| 2 | 结束唤醒 | 到点后声音从无到有淡入，代替敲门 |

不交付：水下浸水喇叭、体感按摩浴缸、默认开着的掩蔽噪声、客人手机歌单的 Hi-Fi。

## 2. 对使用者是什么效果（从科学原理写）

这一节是设计依据。验收时也按这里的通路来测，不按「舒不舒服」一句话验收。

### 2.1 一句话

换能器让舱壁振动。高盐液体把机械能同时送进皮肤和耳蜗。人在**戴耳塞、不碰舱壁、仰浮**时，仍然能听见，并且觉得声音是从身体里起来的，不是舱角有一只喇叭。

没有这条通路，现有音乐系统对漂中的人基本无效。

### 2.2 能量怎么到人身上

触觉换能器不是扬声器。它是固定在舱**外侧**的惯性振子：音圈推动内部质量块，反作用力进舱壁（牛顿第三定律）。舱壁弯曲后，同时向空气和液体辐射：

```
功放电流
  → 换能器里的质量块加速
  → 舱壁振动
       ├─ 推进气腔  → 通路 A：空气声（戴耳塞后几乎到不了鼓膜）
       └─ 推进盐液  → 通路 B：液体里的声压和质点速度
                       └─ 再驱动人体 → 通路 C：皮肤触觉 + 骨导听觉
```

漂里有两件事改写这三条路的权重：

1. **耳塞。** 通路 A 被挡住。人再「听见」，主要不是气导。
2. **几乎不靠固体。** 浴缸靠背、水床垫面都有一个接触斑，振动从那一点进来。漂浮时全身湿皮肤泡在液体里，没有靠背，振动从四面经水进来。

所以主观效果既不像耳机，也不像浴缸靠背的「定点捶」，而像「整个人在轻轻响」。这是耦合方式决定的，不是文案决定的。

### 2.3 为什么必须经水，不能靠空气喇叭

声在界面上反射还是透射，看两边的特性阻抗 \(Z=\rho c\)（密度 × 声速）差多少。

| 介质 | \(Z\) 的数量级 | 和人体软组织比 |
|---|---|---|
| 空气 | 约 \(400\,\mathrm{Pa\cdot s/m}\) | 差约一千倍，界面几乎全反射 |
| 软组织 | 约 \(1.5\times 10^6\) | 基准 |
| 清水 | 约 \(1.5\times 10^6\) | 接近，能量能进皮肤 |
| 运营浓度硫酸镁（约 1.23–1.26 g/cm³） | 密度和声速都比清水高，\(Z\) 更高 | 比清水更容易进浅层组织；脂肪、肌肉、骨头之间仍会反射 |

空气喇叭：能量卡在气–皮肤界面，人靠耳朵听。戴耳塞后这条路断了。

液体耦合：能量能进皮肤和浅层组织。胸腹、背、四肢会同时感到振动。

不要用「液体到皮肤穿透率 98%」那种单界面算法当卖点。进皮肤之后还有多层组织，绝对能量本来也不需要很大：舱里本底极低，刚过听觉/触觉阈值就够。

同一只换能器、同一个驱动电压，清水和盐液里的声压、体感会不一样，因为 \(Z\) 和声速都变了。**量产 EQ 必须在盐液里标定**，不能拿注水调试的曲线直接出厂。

### 2.4 人身上三套感受器，对应三种完全不同的「效果」

同一套舱壁振动会同时打在听觉、触觉、前庭上。频段不同，人感到的东西不同。设计就是在这三套之间做取舍。

#### 听觉：耳蜗，戴耳塞时主要走骨导

耳蜗毛细胞响应的是内耳淋巴里的行波，不在乎能量从鼓膜来还是从骨头来。

戴耳塞以后，气导被堵住。剩下的是经典骨导（Békésy / Tonndorf）加上液体近场：

- **惯性骨导：** 颅骨整体加速，听骨链相对卵圆窗滞后，仍能推动耳蜗。
- **压缩骨导：** 颅骨形变压迫骨迷路。
- **骨–鼓室通路：** 外耳道壁带着耳塞一起振，推动鼓膜。
- **体液传导：** 盐液里的声压经软组织传到乳突和外耳道周围。阻抗匹配后的近场，不是神秘机制。

人实际听到的：

- 低频（大约几十到两百赫兹）会觉得「实、近、从胸口出来」。
- 语音能不能懂，取决于 500 Hz–4 kHz 能不能经壳体和液体/骨导到达耳蜗。壳体是很差的高音喇叭，**语音会闷**。引导词必须：语速慢、口齿清楚、低频能量够、没有嘈杂背景。不要拿普通歌单当默认内容。
- 齿音、镲片基本没有。不要承诺高保真。

行业说「清晰的水下声音」，意思是「戴耳塞也能听见引导」，不是录音室还原。

#### 触觉：这是「身体在听」从哪来的

皮肤和深部的机械感受器对振动的调谐不同（触觉心理物理学的四通路模型）：

| 感受器 | 大致敏感频段 | 人的主观感觉 |
|---|---|---|
| 梅斯纳小体 | 约 10–50 Hz | 浅表的拂、颤 |
| 帕西尼小体 | 约 40–400 Hz，峰值约 200–250 Hz | 深部的嗡、捶、在骨头里 |
| 梅克尔 | 接近直流到数赫兹 | 持续压着 |
| 肌梭 / 腱器 | 整体被推得够明显时 | 「舱在顶我一下」 |

这条产品的主力是帕西尼小体：对加速度敏感、适应快。全身浸在液体里，等于把大量帕西尼接到同一个声场上，所以是整个人在响，不是某一处喇叭在响。

人实际感到的：

- 有低频的声音：胸、腹、大腿会跟着走，像很轻的体感低音，但没有坐垫那个接触点。
- 只有人声、没有低音：体感弱，主要是闷闷地听见。
- 开太大：液面自己起皱，皮肤上出现和内容无关的涟漪痒，安静被破坏。
- 开太小：只有机壳吱吱响，人会以为设备坏了。

胸腹体表刚能感到的加速度大约在 0.01–0.1 m/s² 量级（数量级，必须在本舱用加速度计标定，不写进宣传）。产品目标是同时满足三件事：

1. 引导词听得懂；
2. 胸腹刚过触觉阈；
3. 液面还没皱到客人能抱怨。

功率加到 2 或 3 单独成立、另外两项坏掉，都算没调好。

#### 前庭：这是要切掉的效果，不是卖点

耳石对线加速度敏感。大约 20 Hz 以下、幅度一大，人会晃、胸闷、发慌，少数人恶心。

DSP 上必须有高通，切掉「摇舱」那一段，把能量留在帕西尼和耳蜗还用得上的频段。截止频率用本舱实测，不在方案里写死。

### 2.5 中性浮力会放大还剩下来的信号

陆地上靠椅背听体感音响，重力把背压在一个固体上，振动从接触斑进来，很局部。

漂浮时关节和足底的压力信号被卸掉，大脑对还剩下的皮肤和耳蜗信号更敏感。同样的加速度，在舱里会显得更「大」。所以默认电平必须比浴缸、水床更保守。

人头会慢慢平移、转动。舱里有驻波时，转个头某个频段会忽有忽无——客人的原话会是「有的字听得见、有的听不见」。调校时要在头的活动范围内检查，不能只测一个点。

### 2.6 和水床、浴缸比，人感到的不是同一种东西

工学同源：都是振子打在结构上，再打进一大团水。体验不同：

| | 水床 | 体感浴缸 | 我们要做的漂浮舱 |
|---|---|---|---|
| 振动从哪进身体 | 背侧接触囊面 | 靠背接触 + 水 | 全身经液体，几乎无固体接触 |
| 耳朵 | 在空气里，通常不戴耳塞 | 在空气里 | 半浸，**几乎必戴耳塞** |
| 重力 | 仍压在床上 | 仍坐/躺在缸里 | 中性浮力 |
| 人的主导感觉 | 背在响 | 腰背定点震动 + 空气里的音乐 | 全身轻嗡 + 闷闷的「水下听见」 |

不要把浴缸「体感按摩」话术搬过来。漂浮舱做不到靠背定位的定点刺激，也不该追求。我们能诚实交付的只有两句：戴耳塞也能听见引导；身体有一点点低音。

### 2.7 和深静音是反方向，必须做成两档，默认关

经典漂浮要输入尽量接近零。本功能是故意注入声和触。做成默认常开，等于把安静产品改成水疗浴缸。

| 用法 | 换能器 | 人得到的 | 谁用 |
|---|---|---|---|
| 深静音 | 关、功放使能切断 | 黑、静、暖、失重 | 熟客、要空的人 |
| 引导 / 唤醒 | 开，刚过阈 | 听见慢语或结束音乐，身体轻嗡 | 首漂、要人带着、到点叫醒 |
| 错误 | 一直开很大，或用来盖泵噪 | 涟漪、发晕、以为舱漏电在抖 | 禁止当默认 |

行业里这条功能的真实用途就三件：开场安抚、过程引导、结束唤醒。不是把人「漂得更深」。

本底高（泵、结构声）时，先关泵、先隔振，再考虑加换能器功率。用声音盖噪声，人会更吵，不是更清楚。

### 2.8 对内怎么写、对客怎么说、什么不许说

**实验记录和设计评审只用物理句子：**

- 戴耳塞时气导被阻断；壳体振动经液体进入皮肤机械感受器，并经骨导进入耳蜗。
- 低频同时驱动帕西尼通路和耳蜗，主观上是「身体里有声音」。
- 中性浮力卸掉支撑面压力后，同样的加速度会被觉得更明显。
- 液面起皱后，触觉通道被涟漪占用，引导反而变差。
- 过低过强的加速度打到前庭，产生摇晃和不适。要切掉。

**对客可以说：**

- 戴着耳塞也能听见缓慢的引导；结束时音乐会自己过来，不用敲门。
- 低音会从身体里过来一点点，不是喇叭对着脸。
- 想完全安静，可以关掉。

**任何场合都不许说：** 刺激迷走、激活副交感、细胞共振、频率疗愈、40 Hz、改善睡眠已验证、骨传导助眠数据、音疗 / 声音治疗。那些既不是本装置测到的，也不能当产品功能名。

## 3. 别人的设备具体怎么做

漂浮舱这一行的做法高度一致，直接照这个结构做：

| 谁 | 公开能核实的做法 |
|---|---|
| Dreampod V2 | 舱体前部嵌两只触觉换能器，做水下声学 |
| Dreampod Cabin | 以内壁为声腔，换能器把整个内部变成大扬声器；另卖防振垫（壳体振动会漏进楼板） |
| i-sopod | 换能器激发玻璃钢蒙皮做立体声；双层壳体，夹层空气兼顾保温隔声 |
| Ocean Float Rooms | 换能器分置水上和水下区域，结束时淡入 |
| Float Tank Solutions 行业文 | 贴在玻璃钢外壳上，被贴物当喇叭盆，多数不打孔；用途是结束淡入、避免敲门 |
| Clark Synthesis | 漂浮舱和热水浴缸常用的全频 TST。安装：掀开保温 → 打磨玻璃钢外壁 → 慢固化环氧粘支架 → 再拧上换能器。小缸一只，大缸两只。全天候型号耐潮湿，**不能当水下件用** |

共同选择：

1. 液体里不放喇叭（盐蚀、开孔）。
2. 两只，头侧或前部。
3. 壳体当辐射体。蛋形曲壁驻波少一些；我们的 FA-O 更接近长方，EQ 和摆位更关键，不是做不了。
4. 节目是为「戴耳塞 + 经水」做过的引导轨，不是 SPA 歌单。

水床、体感浴缸是同一物理，但产品形态不同：水床从背侧振一袋水；浴缸常常把「听」和「触」拆成两套换能器，还在四象限里扫振动中心。我们不要做成浴缸那套——漂浮没有靠背，结构也更复杂，调校和故障点都会翻倍。

不要做的第三条路：把多只喇叭吊进盐液，再用一只水听器在会话中实时均衡。盐蚀、密封、维护都差，实验室标定用一次水听器即可，标定结果固化成 EQ 预设。

## 4. 系统怎么构成

```
点点控「音乐舒缓系统」线路输出
    → DSP（高通、EQ、限幅、淡入淡出、两档预设）
    → 功放（4 Ω 稳定，有使能脚）
    → 舱外两只全频触觉换能器
```

会话中没有水听器闭环。EQ 来自第 7 节在盐液、戴耳塞、耳位活动范围内标定的预设。

深静音：DSP 静音 **并且** 切断功放使能，避免底噪。急停、漏电保护与这一路使能串在同一条安全链上。

## 5. 接到 FA-D / FA-O 上

| 机型 | 舱体约尺寸 | 液量（手册口径，以铭牌为准） |
|---|---|---|
| FA-D | 2350 × 1400 × 1400 mm | 有效约 400 L，运行重量约 800 kg 级 |
| FA-O | 3000 × 1800 × 1600 mm | 约 800 L |

三分体：舱体 / 智能主机 / 储液箱。换能器只在舱外干侧。DSP、功放进主机柜，热不要排进舱内气腔。

舱体有亚克力和玻璃钢两种，安装不同：

- **玻璃钢：** 局部去掉保温，打磨出平面，环氧粘厂家支架，固化后再上换能器。力必须进结构层，不能耗在泡沫里。
- **亚克力：** 不要砂穿、不要只点粘。大面积底板把力铺开，机械抱箍或借已有法兰；胶必须兼容亚克力、耐湿热。亚克力共振峰更尖，更依赖 EQ。

第一版摆位（阶段 B 测完可以改）：

- 两只，关于纵轴对称；
- 对应设计液面以下的外侧，靠近头端，但不要在头的正下方（正下方容易在耳位出节点或热点）；
- 不要装在泵、管路、门铰链上；
- 舱脚必须隔振。不隔振：舱内觉得弱，隔壁觉得吵。

点点控改动：

- 三档：关 / 引导 / 结束淡入，默认关；
- 结束淡入与会话倒计时绑定；
- 急停切断换能器；
- 内容分区：引导轨、结束轨与「客人手机输入」分开，手机输入走另一套更保守的 EQ 和限幅。

电气：换能器回路在漏电保护之后；湿区电缆护套；接插件不进舱内。

### 实验室测量（不装进交付品）

| 件 | 用来证明 |
|---|---|

### 只买来做对照、不当量产

Dayton BST-1 ×2 + 小功放：纯低频、几乎没有语音。用来让内部的人听一次「只有抖、没有字」，确认量产不能走这条。

不要买：浸水喇叭、会话用水听器闭环套件、「40 Hz 疗愈」模块、游戏椅套装当交付件。

## 7. 实验和调校（按这个顺序做）

原则：先不砸舱，先分清三条通路，再上盐，再上人。能做清水对照的都做。每一步留波形，不留「感觉可以」。

安全：漏电保护、急停切断功放、盐液里不放通电换能器、电平从低加。前庭敏感、孕周禁忌、未控高血压按现有 SOP 排除。内部受试不是临床试验，不设治疗终点。

### 阶段 A · 同材料小板

目的：换能器和胶接是否在传力。

- 一块与舱同材的板 + 一只换能器，扫频 10 Hz–8 kHz。
- 记录驱动电压 → 板心加速度。共振峰后面要压。
- 用耳朵听一句测试语音：全频 TST 应能听出字；低频振子应几乎听不出字。听不出字就不要拿那只当量产方案。

### 阶段 B · 空舱、不注液

目的：壳体怎么振、漏到楼板多少。

- 两只按拟定位置装上。
- 舱壁网格加速度：头区、胸区、脚端、门、泵座。
- 舱外 1 m 声压、地面加速度。
- **隔振垫有 / 无对照。** 无垫而楼板大：先隔振，再谈体验。

### 阶段 C · 清水到设计液位

目的：三条通路第一次分开。

测点：拟耳位空气麦、拟耳位水听器、胸腹对应舱壁加速度、液面波高。  
激励：固定电压扫频 + 一条标准语音。

要拿到的曲线：

1. 电压 → 液中耳位声压  
2. 电压 → 气腔耳位声压  
3. 电压 → 胸腹加速度  
4. 电压 → 液面波高  
5. 语音哪些音节掉了（记下来，给内容用）

### 阶段 D · 盐液到门店运营密度

把 C 全部重做。用这张对照决定：

- 出厂预设只用盐液档；
- 清水档和盐液档差到可闻/可感，就禁止用注水调试的曲线出厂。

声速可用两只水听器已知间距的时延估一个重复得出来的数，不需要计量院精度。

### 阶段 E · 戴耳塞的内部受试（效果验收）

三种条件随机：关 / 刚过阈 / 明显过阈。同时记仪器和口述。

口述只问四件：引导词能否复述；胸腹有没有轻嗡；有没有摇、晕、痒、怕；水面有没有皱。

仪器：乳突或下颌加速度、耳塞内侧声压、液面波高。

**做成的判据：能复述 + 胸腹刚过阈 + 波高不超过抱怨线。** 问卷只用来解释有人为什么讨厌，不能单独当合格。

再测一次「关」：与改造前本底比，不能更吵，功放使能切断后无底噪。

### 阶段 F · 会不会搞坏安静

换能器开到验收电平，泵开/关各一次，测气腔声、液面波、舱壁温度、邻室声。哪一项明显变差，先降功率或改安装，不加 EQ 硬推。

---

## 8. 怎样算做到设备上了（量产前验收）

全部留波形。做不到 1 和 2 就是没做成，加功率不是办法——先查是否贴在泡沫上、力是否进了楼板、耳位是否落在驻波节点。

1. **戴耳塞可懂：** 内部受试能复述结束引导的关键词；引导频段在液中耳位或乳突加速度上看得见。
2. **体感在阈上、涟漪在阈下：** 胸腹加速度过阈，液面不超过阶段 E 的抱怨线。
3. **不摇舱：** 无人报告明显晃、恶心；头部很低频的加速度低于阶段 E 的不适线。
4. **深静音还在：** 关闭后本底不比改造前差。
5. **不漏楼：** 在真实地面和隔振条件下，邻室可接受。
6. **急停切断换能器。**
7. **出厂 EQ 是盐液档。**
8. **点点控默认关；** 对外话术只允许第 2.8 节那几句。

---

## 9. 内容怎么配

壳体传声不是 Hi-Fi。内容要迁就通路，不能反过来。

- 引导：单声道即可，语速慢，口齿清楚，少齿音词，低频足，无背景音乐抢中频。
- 结束唤醒：从无到有 20–40 秒淡入（具体时间门店可调），低音温和，不要鼓点砸液面。
- 开场可选很短的一段，然后必须能回到静音。不要整场塞满。
- 客人手机输入：限幅更狠、高通更高，作为「自费风险」选项，不作为出厂演示。

阶段 C/D 掉字的音节表，交给录音用。

## 11. 明确不要做的

- 用游戏椅低频振子当量产听音方案。
- 盐液里浸喇叭，会话中用水听器闭环。
- 听一套、触一套、再四象限扫振动中心（浴缸做法）。
- 默认开着盖泵噪声。
- 未隔振就加功率。
- 注清水调好的 EQ 直接出厂。
- 对客讲迷走、40 Hz、细胞共振、音疗。

频率、功率、声压、加速度全部以本舱实测为准，本文件里的数量级只用来选型，不写进铭牌和宣传。
