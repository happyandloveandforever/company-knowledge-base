# 漂浮舱卫生与安全标准五问

> 对应检索问题：NSF CCS-12804 测试方法、30 分钟周转率、臭氧限值与检测、ASTM F462 防滑、ASME A112.19.17 防卡吸。  
> 整理日期：2026-09-04。本文是**公开标准与行业实务摘录**，不是本公司试验报告，也不是认证证书。  
> **对外口径：** 可讲「按 NSF / 北美浮舱实务设计与检测」；具体流量、臭氧残留、认证型号以铭牌、说明书和第三方报告为准，不要口头锁死数字。

---

## 0. 先把三套文件分清

| 文件 | 性质 | 和漂浮舱的关系 |
|------|------|----------------|
| **NSF CCS-12804**（约 2013） | NSF 休闲水项目的**部件认证规范**（Component Certification Specification） | 漂浮 / 感觉剥夺系统的设计、材料、循环、过滤、消杀、寿命试验的第一份公开细则；后来被吸收进 NSF/ANSI/CAN 50 |
| **NSF/ANSI/CAN 50**（2021 起含第 28 节，2025 续更） | 泳池 / 温泉 / 休闲水设施设备与化学品的**共识标准** | 第 28 节 *Floatation or Sensory Deprivation Systems*；认证时按制造商指定的泵、滤器、流量计、撇渣、消杀、吸入口、回水口整系统评 |
| **North American Float Tank Standard**（FTA，v3，2025-05） | 行业协会**运营建议**，不是认证标准 | 用户之间至少 3 次容积翻转（约滤掉 95%）、UV / 臭氧、空气臭氧按 OSHA 管 |

CCS-12804 管**设备能不能过实验室**；FTA 标准管**门店每次客人之间怎么跑循环**。两者数字不同，不要混成一句。

## 1. NSF CCS-12804 的具体测试方法是什么

### 1.1 规范管什么

CCS-12804 评估工厂制造的、自含或非自含、便携或预制的感觉剥夺 / 漂浮系统，覆盖：

- 材料与接触水部件的毒理（NSF/ANSI 50 第 3 节 + Annex A）
- 舱体 / 内衬 / 结构
- 循环、过滤、消杀
- 标识、安装与使用说明

它**不声称**覆盖使用中的全部安全风险；符合性判断以当时的工艺水平为限。

### 1.2 必须引用的外部试验方法（规范开篇清单）

| 主题 | 引用标准 |
|------|----------|
| 休闲水设备总则 | NSF/ANSI 50 |
| 塑料管件 | NSF/ANSI 14（NSF-pw） |
| 吸入口防卡 | ANSI/APSP-16（即 ASME A112.19.8 体系） |
| 预制塑料温泉壳体 | ANSI Z124.7 |
| 塑料浴缸 / 淋浴盆 | ANSI Z124.1.2 |
| 箔 / 薄膜厚度 | ASTM E252、ASTM D374 |
| 入浴面防滑 | **ASTM F462** |
| 塑料拉伸 | ASTM D638 |
| 薄膜拉伸 | ASTM D882 |
| Graves 撕裂 | ASTM D1004 |
| 薄膜静 / 动摩擦系数 | ASTM D1894 |
| 穿刺撕裂扩展 | ASTM D2582 |
| PVC 柔性防水膜 | ASTM D4551 |
| 柔性 PVC 软管 | IAPMO Z1033 |
| 门禁 / 开门报警 | UL 2017 |

### 1.3 内衬与壳体：实验室怎么做

**非增强柔性内衬**须通过：

| 项目 | 方法 | 接受值（CCS-12804） |
|------|------|---------------------|
| 厚度 | 质量法 / 测厚 | ≥ 0.030 in（约 0.76 mm） |
| 穿刺 | ASTM D4551 或 D4833 | 按该方法接受准则 |
| 压痕 | ASTM D4551 | 同上 |
| 静水压 | ASTM D4551 | 同上 |
| 撕裂 | ASTM D1004 | ≥ 225 lb/in |
| 拉伸强度 | ASTM D638 | ≥ 2000 psi |
| 100% 伸长模量 | ASTM D882 | ≥ 950 psi |
| 耐化学品 | NSF/ANSI 50 Annex G.1 | 按制造商最大推荐药剂浓度暴露 100 天，或提供等效耐蚀证明 |
| 不泄漏 | 整舱运行 | 在制造商最大推荐盐浓度与水位下不漏 |

**刚性塑料舱体**按 ANSI Z124.1.2 / Z124.7：耐污、表面 / 次表面、色牢度、耐磨可清洁、香烟灼烧、耐化学品、静水载荷、空载加载、点冲击、阻燃（UL 94 HB/HBF 或 Z124.1.2 §5.6）。

结构限制（常被忽略，但对认证有硬杠）：

- 水深标记须对比色，标在舱外；**水深不得超过 24 in（62 cm）**
- 底坡不大于 1:12（1 in / ft）
- 踏步（若有）：踏面水平深度 ≥ 10 in，面积 ≥ 240 in²；踢面 7–12 in；最低一档作座时可到 14 in
- 拉手：至少一处最低点不高于工作水位以上 9 in；150 lb 拉力或 300 lb 垂向载荷下不永久变形、不脱落

### 1.4 循环与过滤试验（和「能不能过认证」直接相关）

在滤材清洁、泵与滤器最大流量下：

1. **单次容积周转 < 5 分钟**（设备能力，不是门店间隔）
2. 整系统按 NSF/ANSI 50 第 5 节 + Annex B：
   - 静水压：≥ 1.5 × 最低工作压力（最低工作压力按 50 psi 计）
   - 压损
   - 循环性能：回水设计须帮助舱内搅拌并把水抽到处理回路
   - **浊度去除 ≥ 70%**：挑战物为 **Sil-co-sil 106（#140 硅粉）**，在做完制造商规定的「用户之间清洁循环」之后测
   - 滤材可清洁性
   - 有效过滤面积与过滤速率（第一级滤器须达温泉级要求）
3. 泵按 NSF/ANSI 50 温泉温度工况核泵曲线、静压、毛发收集器；并实测「总水量 5 分钟内走完一轮」

撇渣 / 溢流 / 紊流取水另有负压、空气卷入、APSP-16 手指 / 肢体 / 头发 / 躯体卡吸试验（见第 5 问）。

### 1.5 消杀效能：Annex H + 用户间循环

二次处理（臭氧、UV、铜银离子）**必须有至少一种**，并与循环泵电气联锁，只在用户之间的清洁循环里工作。

**初次消毒效能试验（CCS-12804 §1.7.1.4.9.3）**

1. 水位、温度、盐度（及铜银，若用）按制造商说明书
2. 确认水中**无**游离氯 / 溴、**无**过氧化氢或其他氧化剂（测二次系统时关掉一次卤素）
3. 按 NSF/ANSI 50 **Annex H** 接种挑战菌
4. 只跑制造商规定的「用户之间维护 / 清洁」：臭氧、UV、铜银按推荐输出；若产品把过氧化氢与 UV 作为组合，可按规范关掉氧化剂、只评杀虫装置
5. 记录循环进出水、ORP、出水紫外透过率（UVT）
6. **取样点：舱内使用者区域，不是机房取样口**
7. **接受准则：挑战菌 3-log（99.9%）杀灭或灭活**

若系统同时有氯 / 溴（一次）和臭氧 / UV（二次），**效能试验关掉一次卤素**，只评二次系统——这是 CCS 和后来 NSF 50 浮舱条款的核心：高镁溶液里氯溴测不准，认证不能靠氯「凑数」。

### 1.6 3000 小时寿命试验后再测一遍

初次 3-log 通过后，整套处理系统做 **模拟 3000 小时寿命试验**，模拟泵、过滤、UV、臭氧、加药装置每次用户后的反复启停。寿命试验结束后，再按 Annex H 对**两种**挑战菌达到 3-log。过不了这一关，不能声称「寿命期内仍能灭菌」。

### 1.7 铭牌与手册里必须写明的运行信息

- 最大人数、最高推荐温度
- **用户之间清洁循环的步骤和时长**；警告：清洁循环期间舱内不得有人
- 水质参数（规范示例：游离氯 1–5 mg/L 或总溴 2–6 mg/L——这是泳池式一次消毒的写法；北美浮舱运营标准并不推荐日常用氯溴）
- NSF CCS 标志（CCS-12804）

## 2. 漂浮舱过滤系统如何满足 30 分钟周转率要求

### 2.1 「30 分钟」到底是哪一条

三套数字经常被说成同一件事，其实不是：

| 来源 | 要求 | 含义 |
|------|------|------|
| **CCS-12804 §1.7.1.2** | 清洁滤材、最大流量下，**1 次容积周转 < 5 min** | 设备**能力**：泵和滤器够不够大 |
| **NSF/ANSI/CAN 50 第 28 节**（NSF 商业水部门公开说明，2023） | 挑战液在 **最长 30 min 周转时间**内达到 **70% 浊度去除** | 认证**性能**：在允许的周转时限内，过滤真的去掉了颗粒 |
| **FTA 北美浮舱标准 v3 §4.1.6** | 用户之间至少完成 **95% 溶液更新**；无外置储液罐时 = **至少 3 次周转**（鼓励 4 次） | 门店**操作**：客人 A 出舱到客人 B 进舱之间要跑完的循环 |

Gage–Bidwell 稀释律：完全混合再循环时，**3 次周转 ≈ 滤掉 95%**，**4 次 ≈ 98%**。这是 FTA 写「三次」的理由，不是 NSF 实验室的 70% 硅粉浊度试验。

### 2.2 公式：先把流量算够

周转时间（分钟）= 舱液体积 ÷ 循环流量。

因此：循环流量 ≥ 舱液体积 ÷ 允许周转时间。

- \(V\)：舱内漂浮液体积（L 或 gal）
- \(Q\)：循环流量（L/min 或 gpm），须按 **比重 1.23–1.30 的饱和硫酸镁** 读泵曲线，不能用水的清水曲线
- \(t_{\text{允许}}\)：认证取 ≤ 30 min（浊度试验窗口）；设备能力按 CCS 取 ≤ 5 min；门店 3 次周转若要压在 30 min 间隔内，则单次周转 ≤ 10 min

**算例（仅演示算法，不是某型号参数）：**

| 舱液体积 \(V\) | 目标 | 所需最小流量 \(Q\) |
|----------------|------|---------------------|
| 400 L | NSF 50：1 次周转 ≤ 30 min | ≥ 13.3 L/min |
| 400 L | 30 min 内完成 3 次周转（FTA 95%） | ≥ 40 L/min |
| 400 L | CCS：1 次周转 < 5 min | ≥ 80 L/min |
| 175 US gal（约 662 L） | 3 次周转用时 24 min（佛罗里达一份变通申请中的 Quest 套房口径） | 约 22 gpm |

没有流量计时，FTA 要求跟制造商标定的周转时间走，不能用「感觉循环够了」代替。

### 2.3 过滤侧怎样才算「满足」而不只是流量够

流量够只保证水**走过**滤器；NSF 还要求水**被滤干净**：

1. **第一级滤器**须满足 NSF/ANSI 50 第 5 节的**温泉（spa）级**过滤面积与过滤速率，不能拿泳池砂缸的表面负荷直接套小舱。
2. **整系统**（不是单只滤芯）用 Sil-co-sil 106 做挑战，用户间清洁循环结束后浊度下降 ≥ 70%。
3. 表面必须有撇渣能力：溢流篦、天沟、撇渣器或水面紊流取水，把油脂、皮屑、头发从**液面**抽走——漂浮舱的污染物主要在表面，底吸解决不了 70% 浊度。
4. 回水口布置要在舱内形成搅拌，避免死区；否则实验室取样点（使用者区域）过不了，即使机房滤器压差看起来正常。
5. 高镁溶液粘度与密度高于水：同样叶轮在比重 1.25 时流量下降，选型要按**盐溶液工况**留余量，并核对吸入口 APSP-16 的最大允许流量（超了会在防卡试验失败）。
6. 滤材：北美门店多用 1–20 μm 筒式或袋式；孔径越小越清、越容易堵。按制造商周期更换；可重复使用的筒 / 袋应彻底干燥后再装，降低生物膜。
7. **外置储液罐型**：FTA 允许「整舱抽空 → 滤一次 = 100% 处理」算一个过滤周期；北美少见。无外置罐的主流舱必须靠多次再循环凑 95%。

### 2.4 门店操作如何对齐认证

认证测的是「制造商规定的用户间清洁循环」。因此：

- 循环泵、臭氧 / UV 与过滤必须**电气联锁**：循环停，消杀停。
- 客人之间至少跑完说明书写明的循环次数或分钟数；FTA 基线是 3 次周转。
- 开业前、收工后按规程多跑循环，避免隔夜死水（NACCHO 实务常见：开业前约 1 次、收工后约 4 次量级，以说明书为准）。
- 清洁循环期间舱内不得有人（CCS 铭牌强制警告）。

**工程一句话：** 用盐溶液工况把 \(Q\) 选到「5 分钟能走完一舱」（满足 CCS 能力），再用 Sil-co-sil 106 证明 30 分钟窗口内浊度降 70%（满足 NSF 50 第 28 节），门店再按 3 次周转排班（满足 FTA）。三句话都做到，才叫「过滤系统满足 30 分钟周转率要求」。

## 3. 臭氧消毒在漂浮舱中的浓度限制及检测标准

臭氧要同时管**两件事**：水里残留（氧化 / 刺激）和空气里逸散（呼吸毒性）。CCS 把水里的上限写成了带空气单位的括号，实务上应**分层执行**，不要把 ppm（水）和 ppm（空气）当成同一个数。

### 3.1 水中溶解臭氧

| 依据 | 限值 | 测什么 |
|------|------|--------|
| CCS-12804 §1.7.1.4.9.2 | 按 NSF/ANSI 50 **Annex H** 测，**水中臭氧不得超过 0.1 ppm**；原文括号写 0.2 mg/m³（这是空气臭氧 0.1 ppm 的质量浓度换算，单位混用，执行时按「水中 0.1 mg/L」+「空气按 OSHA」两套） | 舱水 / 回水中的溶解 O₃ |
| NSF/ANSI 50 第 13 节 + Annex H | 臭氧发生器的注入方式、产量、关气（off-gassing）、运行保护；产量与寿命试验 | 设备认证，不只是现场试纸 |
| NACCHO 2023 浮舱实务 | 舱液臭氧不宜超过约 **0.1 ppm** | 与 CCS 水中上限一致 |
| PHTA / 泳池行业臭氧说明 | 回水进入主水体时溶解臭氧残留通常约 0.1 ppm 量级，且**几乎不提供长效余氯式残留** | 解释「为什么还要 UV / 过滤 / 用户间循环」 |

漂浮舱里臭氧是**二次处理**，与循环泵联锁，主要在用户之间的循环里工作，不是泡在 0.1 ppm 里供人呼吸。

### 3.2 空气中臭氧（门店真正容易超标的一项）

FTA v3 §4.1.4.5 写明：空气臭氧须在**舱内、舱周、臭氧发生器附近**测量。

| 指标 | 限值 | 法律 / 标准来源 |
|------|------|-----------------|
| PEL（8 h 时间加权平均） | **0.10 ppm（体积）** | OSHA 29 CFR 1910.1000 Table Z-1 |
| STEL（任意 15 min） | **0.30 ppm** | OSHA 1910.1000；FTA 同步引用 |
| 换算 | 0.10 ppm ≈ **0.2 mg/m³**（25 °C） | 与 CCS 括号中的 0.2 mg/m³ 对应的是**空气**，不是水 |

FTA 附录强调：员工进舱擦洗时风险最高，这时该看 **STEL**，不是 8 小时 PEL。NSF/ANSI 50-2025 在第 28.11 节为浮舱系统补了**空气质量测试**条款，认证侧也开始管舱内空气，而不只是机房设备。

发生器选型过大、舱体密闭、房间通风不足，是超标的典型组合。发生器必须按舱容积选型。

### 3.3 检测标准与方法

**水中溶解臭氧**

| 方法 | 标准 / 仪器 | 要点 |
|------|-------------|------|
| 靛蓝三磺酸盐比色 | APHA Standard Methods **4500-O3 B**；ISO 同类靛蓝法；Hach Method 8311（AccuVac） | 臭氧使靛蓝在 **600 nm** 褪色；低量程约 0–0.25 mg/L，分辨约 0.01 mg/L；取样要避免曝气逸散（真空安瓿优于倒杯） |
| 现场 ORP | NSF 50 臭氧设备可要求 ORP 监测 | FTA：**仅过氧化氢**时 ORP 约 300 mV（pH 7）；有臭氧或氯时往往 > 650 mV。ORP **不是**浮舱卫生合格的法定指标，只作趋势 |
| 认证试验 | NSF/ANSI 50 **Annex H** | 实验室按注入方式、关气、水中残留是否超 0.1 ppm 判定，不是门店试纸 |

高浓度硫酸镁会干扰部分泳池试纸（NSF 对氯的研究已证实）。溶解臭氧同样不要用「泳池氯试纸」凑数；用靛蓝法或臭氧专用试剂。

**空气臭氧**

| 方法 | 标准 | 适用 |
|------|------|------|
| 紫外光度计 | OSHA **ID-214** | 实验室 / 工业卫生定点 |
| 电化学个人采样器 | 工业卫生常用，须按说明书校准 | 员工 STEL / PEL |
| 检测管 | 厂家方法，精度较低 | 筛查，不能当唯一合规证据 |

测点：舱内使用者呼吸带、开门瞬间、发生器机柜缝、房间回风口。循环刚结束、舱门开启时最容易看到峰值。

### 3.4 和氯 / 溴 / 过氧化氢的关系

- 北美浮舱标准：**主策略是 UV、臭氧或二者组合**；过氧化氢可作氧化剂协助澄清，上限 **100 ppm**（体感微泡，不是毒理上限）。
- 氯、溴：EPA 未按浮舱用途注册；高镁溶液里多数余氯试纸不准（NSF 2015《Recovery analysis of free and total chlorine measurement methods in high MgSO4 solution》）。CCS 仍写了一次卤素加药的实验室条款，那是为了兼容地方卫生局仍要求「泳池式加氯」的辖区，**不是**北美浮舱运营推荐。
- 污染事件（成形粪便 / 血）：FTA 用 2 ppm 游离氯维持 30 min，再用过氧化氢中和——这是应急，不是日常臭氧替代。

**对外可讲：** 臭氧按 NSF 50 Annex H 做产量与关气，水中残留按 0.1 mg/L 量级管理，空气按 OSHA 0.10 / 0.30 ppm 管理，并用靛蓝法和空气检测仪复核。  
**不要讲：** 「臭氧无残留所以不用测」或把水中 0.1 ppm 和空气 0.1 ppm 说成同一个合格证。

## 4. NSF/ANSI/CAN 50 中关于材料防滑的 ASTM F462 细节

### 4.1 它在浮舱标准里出现的位置

CCS-12804 §1.5.3.2（并被 NSF/ANSI/CAN 50 第 28 节吸收）：

> 舱内主要用于进出的踏步或落脚面，须为防滑表面，定义为符合：  
> - **ASTM F462** *Standard Consumer Safety Specification for Slip-Resistant Bathing Facilities*，或  
> - **ASTM D1894**（薄膜 / 片材静、动摩擦系数），视表面材料而定。

也就是说：NSF 50 浮舱条款对**入浴踏步**点名的是 F462（或薄膜用 D1894），**不是**后来给嬉水铺面写的摆锤 SRV≥40。

### 4.2 ASTM F462 本身怎么测

| 项 | 内容 |
|----|------|
| 标准号 | ASTM F462-79，2007 再确认；**2016 年撤回，迄今无正式替代件** |
| 范围 | 浴缸、淋浴盆及组合入浴设施的防滑 |
| 仪器 | **NBS–Brungraber Mark I** 便携式静摩擦系数仪（NBS 即后来的 NIST 资助、Brungraber 1975 年设计） |
| 试块 | 浇注硅橡胶，历史上指定 **Dow Corning Silastic 382**（已停产；后人常用相近硅橡胶，与原配方是否可比存在争议） |
| 污染物 | 肥皂水溶液。肥皂须符合已废止的联邦规格 **P-S-624G** 或 **ASTM D799**（2000 年撤回）；文献记载试验常用约 **1:4 肥皂:水** |
| 液膜 | 试块坐在 **0.5–1.5 in（约 12–38 mm）** 深的皂液池里再启动——模拟「皂液没过脚」而不是薄水膜 |
| 测点 | 入浴面多个位置 |
| 合格线 | **静摩擦系数 SCOF ≥ 0.04** |

### 4.3 必须知道的限度（对外不要吹成「防滑认证」）

1. **0.04 几乎贴着仪器零点。** Mark I 在水平面上有效零读数约 0.01–0.02；0.04 只比「测不出来」高一点。该阈值在 1970 年代按「当时 95% 量产浴缸能过」选定，**不是**按人体步态所需摩擦力选定。
2. 皂液浓度远高于真人洗澡，且不同符合 P-S-624G 的肥皂是否改变读数，当年没有系统研究。
3. 标准已撤回；CPSC 正资助 ASTM F15.03 做「F462+」，倾向用 **British Pendulum（摆锤）+ Slider 55（裸足橡胶）**。这是未来方向，**还不是** CCS-12804 的现行引用。
4. NSF/ANSI/CAN 50 **第 26 节**（2019 起，互动嬉水铺面）用的是另一套：湿态 **SRV / BPN ≥ 40**（摆锤）。那是嬉水公园地板，**不要**把「NSF 50 防滑=SRV 40」套到浮舱踏步上，除非该部件是按第 26 节单独认证的铺面。

### 4.4 浮舱工程上怎么落地

- 进出踏步、门槛、舱内落脚区：按 F462 或 D1894 选材 / 做纹理；金属拉手须耐蚀（SS304 或更好）且不可徒手拆掉。
- 舱外淋浴区、更衣地面：按地方建筑 / 无障碍规范另做防滑（往往是摆锤或 DIN 51097 裸足等级），不要只用 F462 一张报告覆盖全店。
- FTA 明确：浮舱场景里**最显著的伤害风险是滑倒**，不是溺水。防滑是运营问题，不只是认证附件。

**对外可讲：** 进出踏步按入浴设施防滑规范（ASTM F462 / D1894）设计。  
**不要讲：** 「已通过 ASTM F462 所以绝对不会滑」——阈值极低，且标准已撤回。

## 5. 漂浮舱防卡吸系统 ASME A112.19.17 的具体规范

### 5.1 这支标准管什么、不管什么

**ASME A112.19.17-2010 (R2023)**  
*Manufactured Safety Vacuum Release Systems (SVRS) for Residential and Commercial Swimming Pool, Spa, Hot Tub, and Wading Pool Suction Systems*

| 管 | 不管 |
|----|------|
| **SVRS 器件**：探测吸入口真空骤升，用**向泵引入空气**和 / 或**切断泵电机**把真空卸掉，避免人体或肢体被吸在排出口上 | 头发缠绕、机械卡入（首饰、脐部）、肠管脱出等其他卡吸形态——那些主要靠 **APSP-16 / PHTA-16 吸入口盖** |
| 通用要求、尺寸公差、材料、安装说明、试验、标识 | 某一套现场管路「装上就一定安全」——标准写明：符合性只表明器件达到本标准性能；**具体循环系统上的效果由设计负责人验证** |

现行文本是 **2010 版、2023 再确认**，技术内容自 2010 年以来未随变频泵更新。CPSC 已指出：DOE 能效规则推行变频泵后，运行真空本身较低，部分 SVRS **可能分不清「变频降速」和「人体封堵」**。ASTM F2387-21 已补变频工况；ASME 本标准尚未同步。选型时要问供应商是否按现场泵型（定频 / 变频）做过验证。

### 5.2 漂浮舱认证怎么引用它

CCS-12804 §1.6.2：

> 使用 SVRS 的感觉剥夺系统，其 SVRS 须由具备该试验标准 **ISO 17025** 资质、且作为泳池产品认证机构具备 **ISO 17021** 资质的独立第三方，按 **ASME A112.19.17 或 ASTM F2387** 的最新要求认证。

同时，NSF 50 浮舱条款要求循环系统**两个或以上吸入口**；吸入口本身须按 **APSP-16** 认证，并遵守该产品清单上的：

- 安装方位（底 / 壁）
- 单只或必须成对
- 所接开孔对应的**最大流量**

没有合格吸入口、却把泵开着让人进舱：CCS 要求手册**禁止在循环泵运行时入舱**。

### 5.3 SVRS 的性能意图（A112.19.17 公开摘要 + VGBA 实务）

VGBA（《弗吉尼亚·格雷姆·贝克泳池与温泉安全法》）把 ASME A112.19.17 与 ASTM F2387 并列，作为公共泳池「可封堵单排口」的二次防卡手段之一。器件层面的共同要求是：

1. **探测**：吸入口被模拟人体封堵、真空骤升时，SVRS 须识别该事件（而不是普通的滤器变脏）。
2. **释放**：在规范规定的时限内卸掉真空——行业与 VGBA 实施文件普遍引用 **3 秒内**释放或停泵，使封堵物可被移开；具体接受值以购得的标准文本和该型号试验报告为准。
3. **保持安全态**：释放后不得在无人工复位的情况下再次建立足以吸住人体的真空（防「松开又吸上」）。
4. **故障安全**：SVRS 自身故障时，不得让泵在无保护状态下继续吸；并须有「系统在工作」的指示，防止被旁路。
5. **安装边界**：制造商须给出适用的管长、弯头数、泵功率 / 流量范围；试验在这些边界上进行。现场超边界安装，证书无效。
6. **标识**：永久铭牌，标明符合 A112.19.17、型号、电气参数、复位方式。

**3 秒**是公开文件和制造商说明书里最常见的释放时限表述；完整试验矩阵（挡板尺寸、试验流量点、循环次数、温度）在 ASME 版权文本中，本文不转抄收费条款。采购时直接向供应商要 **A112.19.17 或 F2387 的第三方试验报告**，核对泵型和管网是否在报告覆盖范围内。

### 5.4 浮舱上防卡吸是「一层盖 + 一层系统」，不是只装 SVRS

CCS 对**水面紊流取水 / 非标准吸入口**还要求按 APSP-16 做全套：

| 试验 | 目的 |
|------|------|
| Finger admittance / entrapment | 手指伸入开孔是否卡住 |
| Limb admittance / entrapment | 肢体 |
| Hair entrapment | 全系统流量、清洁滤材条件下头发缠绕 |
| Body entrapment | 躯体封堵产生的吸力 |
| 300 lb 垂向载荷 | 篦子 / 取水件受踩压后不得变形出新的卡入几何 |
| 户外 UV（若适用） | 拉伸与冲击保留 ≥ 70% |

撇渣器喉口须通向大气（盖上开孔、堰口通气或真空破坏管），避免堰板关闭时把人吸在撇渣口上；非暗藏撇渣器壳体须能承受 **25 in Hg（85 kPa）** 负压不坏。

双吸入口管路须**等长、等径**水力平衡，避免一只被堵后另一只流量翻倍、超过 APSP-16 额定值。

### 5.5 和泳池 VGBA 的差别（避免把泳池条款整段搬进浮舱标书）

- 浮舱 CCS：**水深 ≤ 24 in**，单人、用户之间才开泵；卡吸暴露时间短于泳池主排水。
- 但高盐溶液密度大，同样流量下动量与密封性不同于淡水，**不能**因为水浅就省略合格吸入口。
- SVRS 是「若采用则必须认证」；不是每一台浮舱都强制带 SVRS。没有 SVRS 时，须靠双吸入口 + APSP-16 盖 + 「循环时禁止入舱」把风险关掉。
- 变频泵 + 旧版 A112.19.17：要书面确认兼容，否则改用 F2387-21 器件或定频并在清洁循环用定时器。

**对外可讲：** 吸入口按 APSP-16，成对布置；若配备真空释放装置，则按 ASME A112.19.17 或 ASTM F2387 由具备资质的实验室认证。  
**不要讲：** 「有 SVRS 就不会卡头发」或把未覆盖变频泵的 2010 证书用在新变频机组上。

## 6. 五问对照（给工程 / 尽调一页纸）

| 问题 | 认证侧硬杠 | 门店侧硬杠 | 常见误读 |
|------|------------|------------|----------|
| CCS-12804 测什么 | 材料 + 内衬力学 + **5 min 周转能力** + Sil-co-sil 70% 浊度 + Annex H **3-log** + **3000 h** 后再 3-log | 按铭牌做用户间循环；循环时舱内无人 | 把 CCS 当成「卫生局巡检手册」 |
| 30 min 周转 | NSF 50：≤30 min 内 70% 浊度去除 | FTA：用户间 ≥3 次周转（≈95%） | 把 30 min、5 min、3 次周转说成同一个数 |
| 臭氧 | 水中约 **0.1 mg/L**（Annex H）；关气 | 空气 **PEL 0.10 / STEL 0.30 ppm**；靛蓝法 + 空气仪 | 水、气两个 0.1 ppm 混用；氯试纸测臭氧 |
| ASTM F462 | 踏步 SCOF ≥ 0.04（皂液、Mark I） | 全店地面另按地方规范 | 用嬉水铺面 SRV 40 替代 F462，或夸大 0.04 的人体意义 |
| A112.19.17 | SVRS 第三方认证；吸入口 APSP-16；建议双吸口 | 循环时禁止入舱（若吸入口未按清单安装） | 只装 SVRS、省略篦子；变频泵套用 2010 证书 |
