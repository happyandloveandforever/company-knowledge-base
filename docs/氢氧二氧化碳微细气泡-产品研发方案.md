# 氧 / 氢 / 二氧化碳微细气泡 — 产品研发方案

> 给研发和工程用：怎么把氢浴、碳酸微泡接到现有漂浮舱上。  
> **不是专利申请稿。不入库专利库。**  
> 对照来源：洗浴纳米泡典型机型（WO2016023394A1）、日本氢浴 / 氢碳浴商品与温泉工程。  
> 现役液路 **没有** 这套模块。总库冠军系列写过「纳米水溶氢 / 医疗级增氧 / 碳氧气」，那是材料口径，不是本机已装的硬件。

**先做哪条：** 外购 PEM 产氢 + 耐盐气液混合器，先在水桶里用清水和高盐对照。安全过关再改舱。三种气不要同时打；氢和臭氧永久互斥。

---

## 1. 这个功能到底是什么

口头说「纳米氢」「碳酸泉」「氢氧浴」，工程上是四件可测量的事。混在一起，就会把「看见白雾」当成「氢已经饱和」。

### 1.1 气体种类

| 气体 | 液体里它是什么 | 舱门关上之后它去哪 | 和现有设备的关系 |
|---|---|---|---|
| **氢 H₂** | 分子氢。清水 20℃、1 大气压大约最多溶 **1.6 ppm**；36℃更低；硫酸镁再压一截 | 比空气轻，堆在舱顶。空气里 **4% 体积** 就能爆 | 会把臭氧消耗掉。**氢、氧、臭氧不能一起打** |
| **氧 O₂** | 溶解氧。36℃ 清水、空气平衡大约几 mg/L | 头空间氧超过 **23.5%** 按富氧管，助燃 | 冠军材料写过舱内氧 21–22%。那是「别缺氧」，不是氧浴 |
| **二氧化碳 CO₂** | 溶解 CO₂。日本温泉法：≥250 ppm 叫碳酸泉，≥1000 ppm 叫高浓度 | 比空气重，沉在鼻子高度。多了会闷 | 会把 pH 拉酸，和现在 7–7.8 的维护窗口打架 |
| **混合气** | 各气体按自己的分压分别溶解 | 氢氧预混本身就可燃 | 日本医用 **氢 66.6% : 氧 33.3%** 是开放空间 **吸入**，不是门锁舱配方 |

氢难溶、易燃，卖点是「溶进去且留得住」。  
氧好溶，若只把头顶空气维持在 21%，客人感觉不到差别。  
二氧化碳最好溶、体感最明显（皮肤发红、暖），也最容易从液面逃进鼻子前面。

### 1.2 比例（进水之前的气体配方）

| 配方 | 别人怎么用 | 我们能不能原样搬进舱 |
|---|---|---|
| 纯氢，纯度 ≥99.99% | 麦克赛尔氢浴、H2 Vibe、日本温浴 UFB 氢泉 | **首选。** 电解会同时出氧，氧必须排到室外，不要进舱 |
| 氢 : 氧 ≈ 2 : 1 | 日本氢氧吸入器；公司实验稿里的雾化比 | **禁止作舱内供气。** 门锁头空间 = 头顶预混可燃气 |
| 氧 93–95% + 二氧化碳 5–7%（材料称碳氧气） | 冠军系列；医学上接近 carbogen | **禁止作门锁舱气相。** 高氧加高二氧化碳对呼吸危险 |
| 纯二氧化碳 | 三菱化学人工碳酸泉、夏普纳米碳酸浴缸 | 可以做液体目标；头顶必须把气抽走 |
| 氢和二氧化碳分时 | 日本温浴「水素泉 + 碳酸泉」同一只喷嘴换气源 | **做成两个模式，不要混成一股气** |

「比例」只描述还没进水的气体。进水以后改口说浓度。

### 1.3 浓度（液体一张表，空气一张表）

**液体里（这才叫「浴」）**

| 指标 | 清水、商品常见值 | 我们 36℃、比重 1.25 的硫酸镁 |
|---|---|---|
| 溶解氢 | 家用电解棒约 **0.1 ppm**（麦克赛尔，200 L、15 分钟）；商用循环 30–60 分钟约 **0.8–1 ppm**；物理上限约 **1.6 ppm** | 一定更低。台架没测到数，禁止对外写任何 ppm |
| 溶解 CO₂ | 入浴剂 50–150 ppm；人工碳酸泉宣传 **≥1000 ppm** | 盐更难溶、膜更容易结垢。1000 ppm 先当达不到，测到再定档 |
| 溶解氧 | 空气平衡数 mg/L | 可做，和氢互斥；漂浮体感增量不大 |

教材里出现过「10000 ppb」「万级 ppm」。物理上：1.6 ppm = 1600 ppb，这是清水饱和量级。**万级 ppm 当溶解氢不可能**，不能上铭牌。

研发第一档目标（台架达标后再锁铭牌）：**溶解氢 ≥0.3 ppm，停气后 20 分钟衰减不超过一半。**

**空气里（安全上限，不是功效）**

| 气体 | 建议切断（用本机容积标定后可改） | 原因 |
|---|---|---|
| 氢 | **1%** 降功率；**2%** 停气强排；**4%** 是爆炸下限 | 蛋形舱顶是氢口袋 |
| 氧 | 保持 **20–22%**；超过 **23.5%** 停机 | 21–22% 只是正常空气 |
| 二氧化碳 | **0.5%** 告警；**1%** 停气通风 | 沉在口鼻高度，人先闷 |

我们的舱比日本家用浴缸更密闭。逸气在别人那里是浪费，在我们这里是危险。

### 1.4 气泡尺寸（看得见 vs 留得住）

按 ISO 20480-1：

| 名称 | 直径 | 水里的样子 | 浴用上像什么 |
|---|---|---|---|
| 大气泡 | ≥100 μm | 秒级上浮、哗哗响 | 按摩浴缸气泡垫 |
| **微气泡** | **1–100 μm** | 升得慢，整缸发白，贴皮肤 | 麦克赛尔标称平均约 **40 μm**，每分钟约 3 亿个 |
| **超微细气泡**（常被叫纳米泡） | **<1 μm**，实测常见 100–200 nm | 几乎不上浮，液体可以仍清 | 用来把气锁在水里；肉眼不一定看得见 |

两条广告陷阱：

1. **发白 ≠ 纳米。** 发白是微米泡散射可见光。
2. **发白 ≠ 氢高。** 溶解氢要用溶氢仪。ORP 只能粗筛。

接到本机还要记住：气泡会挡紫外、会让水下声音变糊。所以不是越小越好，也不是越白越好。

| 产品模式 | 主尺寸 | 目的 |
|---|---|---|
| 氢浴（留氢） | 超微细为主，微气泡为辅 | 少往舱顶吐氢 |
| 碳酸泉（贴肤发白） | 微气泡 10–50 μm | 皮肤上能看见小泡，这是碳酸泉的体感 |
| 氧浴 | 超微细 | 头空间氧不要乱飘 |

## 2. 工学原理：为什么市面机器都长一个样

### 2.1 加压把气推进水里，一降压才长出泡

气体能溶多少 ≈ 该气体的分压 × 亨利系数。温度越高、盐越浓，系数越差。所以正经泡浴机都是同一条链：

```
气源（电解 / 钢瓶 / 制氧）
  → 加压（通常 2–5 bar）
  → 气液接触（混合泵 / 文丘里 / 填料腔 / 中空纤维膜）
  → 保压停留几十秒
  → 喷嘴一放
  → 过饱和 → 成核 → 微细气泡
```

WO2016023394A1 把这条写得很完整：混合器至少 1 bar，填料粒径 0.5–10 mm，可再加转子定子；溶好的水进常压浴缸后析出微泡；浴缸带盖还要负压抽逸气。气体清单包括二氧化碳、氧、氢、臭氧和它们的混合物。

日本 ISO 20480-3 把发生方法分成加压溶解、空化、剪切、电解。商品机是这些积木的组合，不是新物理。**我们买现成混合器，不自研一条看起来很像的填料腔。**

### 2.2 我们的液体天生跟溶气作对

硫酸镁比重 1.24–1.27、36℃，三件事同时发生：

1. **盐析。** 离子越多，氢、氧、二氧化碳越难溶。海水已经让氧少一截，我们比海水浓得多。
2. **升温。** 36℃ 比 20℃ 更难溶氢和二氧化碳。日本「40℃ 还能 1000 ppm」靠膜法加压，不是往缸里扔钢瓶。
3. **密度和粘度。** 泡受到的浮力差变大，微泡可能升得比清水更快；粘度升高又会拖住它。谁赢必须测，不能抄日本家用浴缸的衰减曲线。

所以日本官网 0.1–1.6 ppm 的数字，不能印到我们说明书上。

### 2.3 使用者为什么会有体感

- 微气泡表面积大、容易贴皮肤，破裂时有很轻的局部扰动。广告写成「冲击洗净」。实际能感到的是滑、白雾、保温。
- 超微细气泡几乎不上浮，相当于缓释。**关掉发生器，液体里的气还会继续往头顶冒。** 排风必须比停气多开一段时间。
- 二氧化碳经皮吸收后局部变酸，末梢血管扩张（碳酸泉文献里最站得住的一条）。皮肤发红、暖。这不是疾病治疗许可。
- 分子氢极小，理论上能扩散。经皮到底进多少、进了是不是等于喝氢水，没有漂浮舱级的剂量数据。对外不要讲成给药。

### 2.4 密闭舱把「逸气」从浪费变成危险

日本家用氢浴功率大约 24 W，浴缸开着，房间换气把氢稀释掉。  
我们：门锁、头空间小、人躺 45–60 分钟、顶上是氢口袋、鼻子高度是二氧化碳口袋。

设计必须按这个做：

- 氢从顶部抽。
- 二氧化碳从口鼻高度抽，只装顶排不够。
- 排风坏了 = 立刻停气，并允许按 SOP 开门。
- 头空间传感器会结盐。读数一直「正常」也要当故障，不能只信传感器自检。

## 3. 类似设备怎么做（按路线学，不按品牌神话）

### 路线 A · 整机丢进浴缸电解 — 日本家用氢浴

代表：日立麦克赛尔 llexam MHY-B01 / B02。

- 丢进约 200 L 热水，铂钛电极电解，泵把泡撕开。
- 标称：平均约 40 μm，约 3 亿个/分钟，15 分钟溶解氢约 **0.1 ppm**，停机后 45 分钟还能留约 83%。
- 便宜、简单。氢和氧在电极旁边一起产生。开放浴缸能接受。
- **不要搬到本机。** 高电导硫酸镁会让电解失控、电极腐蚀；密闭舱还把氢氧一起产进同一缸液体。

### 路线 B · PEM 产氢 + 混合泵 / UFB 喷嘴 — 商用氢浴（推荐骨架）

代表：欧洲 H2 Vibe（600 mL/min，20 分钟把 175 L 做到约 1.56 ppm）；日本东商 UFB DUAL（钢瓶 99.9999% 氢 + UFB 喷嘴，60–260 L/min）；商用水素微泡机宣传 0.8–1 ppm。

- PEM 只喝纯水，氢氧可以分路：氢进混合器，氧排室外。
- 混合器：气液混合泵（自吸大约 8–10% 气体，出口 2–4 bar）或专用 UFB 喷嘴。
- **这是我们该买的骨架。** PEM 和高盐液彻底分开。

### 路线 C · 中空纤维膜溶二氧化碳 — 日本人工碳酸泉行业做法

代表：三菱化学 Aqua Solutions MR 碳酸泉，宣传 40℃ 仍 ≥1000 ppm。

- 气走膜丝里面，热水走外面，不靠大气泡搅拌。
- 开放浴池要持续补气，溶解的二氧化碳会从液面逃。
- **本机先不当主方案。** 膜孔会被高盐和镁垢堵死。最多买一件做清水对照。

### 路线 D · 加压 + 填料混合腔

就是 WO2016023394A1 那条：气源、水泵、填料腔、可选转子定子、气液分离、带盖抽气。  
采购时让供应商出流道图和材质清单，过盐工况能用再买。不要我们自己画一条很像的腔。

### 路线 E · 钢瓶二氧化碳 + 循环泵 — 夏普纳米碳酸浴缸一类

钢瓶 → 减压 → 针阀 → 气液混合泵 → 浴缸循环。可以切到空气泡。  
结构可以当「碳酸旁路」参考。说明书里的疾病语言不要抄。

### 路线 F · 氢和碳酸共用一只喷嘴、换气源

日本温浴工程已经这么干。正确学法：一台混合器，两路气，**电磁阀互锁，任何时刻只开一路。** 不要学成三种气一起打。

### 路线 G · 氢氧 2:1 吸入 — 边界必须划清

那是呼吸设备，人在开放或有监护的环境里。  
门锁漂浮舱用同一个比例 = 头顶预混可燃气。  
如果以后要做吸入：**出舱后面罩，独立机器，永远不进舱液、不进头空间。**

## 4. 对使用者有什么效果（分三层，避免把广告写进研发目标）

漂浮本身已经能让人放松。气泡模块的增量必须做成 **同一个人、同一台舱、开泡 vs 关泡**。否则全是漂浮的功劳。

### 当场能感到的（优先做，也最好证）

| 模式 | 人可能感到 | 原因 | 实验看什么 |
|---|---|---|---|
| 微气泡（不管什么气） | 皮肤滑、发白、轻刺、比较暖 | 微泡贴肤，少对流散热 | 红外皮温、出舱温热打分、照片看白雾 |
| 碳酸微泡 | 皮肤发红、暖 | 经皮二氧化碳 → 局部血管扩张 | 皮温、肤色、主观。不拿血压当疗效 |
| 超微细氢泡 | 往往看不见，最多一点点滑 | 真把氢溶上去了，体感可能很弱 | **溶氢仪说了算**，不能靠白雾 |
| 头顶 21–22% 氧 | 和普通空气几乎一样 | 不是治疗性富氧 | 只作安全监测，不当卖点 |

### 文献里有、但剂量对不上我们舱的

- 分子氢：研究多半是喝氢水或吸入，不是 36℃ 饱和镁盐里泡 45 分钟。
- 高浓度碳酸泉（≥1000 ppm）：欧洲/日本温泉有末梢循环方向的传统。我们能不能到 1000 ppm 未知，达不到就不要叫「疗养泉」。
- 自由基、线粒体：机制故事，不是本机已经测过的剂量。

### 对外不要说

治疗、抗衰、升免疫、治病、经皮氢等于给药、单次皮肤色度升一号、万级 ppm 氢。

说明书必须写的风险：氢积在舱顶遇火源；二氧化碳积在鼻子前会闷、会慌，和漂浮里的过度换气不好分，处置仍是先出舱；氧多了助燃。开放伤口、严重心肺、妊娠仍按现有禁忌，不因「氢浴」放宽。

## 5. 接到现有设备上怎么改

### 5.1 本机约束

| 项目 | 现况 |
|---|---|
| 架构 | 舱体 + 智能主机 + 独立储液 |
| 舱液 | 有效约 400 L，总约 500 L；硫酸镁 1.24–1.27；36 ± 0.5℃ |
| 卫生 | 回收 → 精滤（材料口径最小 0.1 μm）→ 臭氧 / 紫外 / 光触媒 → 储液 → 再注 |
| 门 | 密闭可锁，头空间小 |
| 气泡模块 | **未装** |

0.1 μm 滤芯会把微泡当颗粒拦住，也会被气堵住。气泡支路接在 **精滤之后、臭氧之前**，体验时回舱不再进臭氧接触器。

### 5.2 推荐管路

```
PEM 电解槽 ──自己的纯水── 氢（氧排室外）── 阻火器 ── 流量计
CO₂ 食品钢瓶 ── 双级减压 ── 流量计
                         │
                         ├── 互锁阀：任何时刻只开一路；臭氧开则全关
                         ▼
              耐盐气液混合器 ── 保压罐 ── 释放喷嘴 ── 舱底
                         ▲
舱液 ── 毛发滤 ── 主泵 ── 精滤 ──┬── 无人消杀：走臭氧 / 紫外
                               └── 有人体验：进气泡旁路

头空间：顶测氢、口鼻高度测二氧化碳、中部测氧
排风：顶排 + 口鼻高度排，断电保持开
门锁：没到位不能产气；超标先停气再排，排完再按 SOP 决定开门
```

控制器写死三条，不要只写在说明书里：

1. 氢开 → 氧关、臭氧关、光触媒放电关。  
2. 碳酸开 → 氢关、臭氧关。  
3. 消杀开 → 全部气源关，排风一直开到头顶气体回到基线。

PEM **禁止**用漂浮液当电解液。它有自己的去离子水箱。

### 5.3 材质

热浓硫酸镁，316 不锈钢长期不够。过盐零件优先钛、PVDF、PTFE、哈氏合金。混合器和喷嘴按海水 / 卤水工况选型，不要买自来水微泡头。密封件用氟橡胶或 PTFE，不要普通丁腈。

### 5.4 和现有模块怎么共处

| 会打架的地方 | 做法 |
|---|---|
| 臭氧、光触媒放电 vs 氢 | 硬件互锁，管里不留死气 |
| 紫外 vs 气泡 | 体验时紫外可以开（无放电），但要测透光；消杀时间可能要加长 |
| 精滤 vs 微泡 | 体验走旁路；滤芯按压差换，不按日历 |
| 水下扬声器 | 开泡前后各测一次舱内声压，差太大就体验时关掉声振 |
| pH | 碳酸会拉酸；这位客人结束后必须调回 SOP，再接待下一位 |

## 6. 采购清单（先买台架，再改舱）

先买能在水桶里跑通的。舱体开孔放到台架过关之后。

### 气源

| 件 | 规格方向 | 备注 |
|---|---|---|
| PEM 氢发生器 | 300–600 mL/min，纯度 ≥99.99%，**氢氧分路**，钛电极 | 400 L 要在 20 分钟内贴近饱和，600 mL/min 是起点。不要买混合气出口的型号 |
| 氢气阻火器 + 单向阀 | 氢气管专用 | 进混合器之前 |
| 食品级 CO₂ 钢瓶 + 双级减压 + 加热减压器 | 防干冰堵阀 | 钢瓶放机房，不进客区 |
| 氧气源 | 可选 | 只给无人台架对照。第一版量产可以不上氧浴 |

### 溶气 / 制泡

| 件 | 规格方向 | 备注 |
|---|---|---|
| 气液混合泵或 UFB 喷嘴 | 过流件钛或 PVDF；旁路 20–60 L/min 即可 | 要海水工况样本和材质证明 |
| 保压罐 | 2–5 bar，停留 ≥30 秒，安全阀 | 内壁同样耐镁盐 |
| 释放喷嘴 | 孔径可换，方便调泡径 | 装舱底，斜向上，避开回水口对吹 |
| 旁路阀组 | 电动 + 手动；断电回到「旁路切断、主循环可消杀」 | |

### 测量（没有这些，实验等于没做）

| 件 | 锁哪一个数 |
|---|---|
| 溶解氢仪（膜电极；TRUSTLEX 一类便携也行） | 液相氢。ORP 只作辅 |
| 溶解氧仪 | 液相氧；也看开氢时氧有没有被顶掉 |
| pH + 电导 + 温度 | 碳酸模式的代理。pH 下降 ≠ 已经 1000 ppm |
| 溶解 CO₂ 或总无机碳 | 有就上；没有就用标定过的 pH–碱度反算，写明误差 |

| 气泡尺寸外包 | 激光衍射或纳米颗粒追踪，清水 vs 高盐各一份 |

### 安全与消耗

不产生电火花的排风、可记数据的控制器、氢气检漏液、亚甲基蓝滴定（粗筛）、比重计、红外或皮温探头、主观打分表、无火种机房。

**先不要买：** 缸内电解棒、中空纤维碳酸膜主机、氢氧混合出口的 PEM、只看广告的「纳米氢发生器」。

## 7. 实验：过关才许装到客舱

每一步都做两套：**清水 36℃**，和 **本机配方硫酸镁 36℃、比重 1.25**。高盐明显更差，就降低目标或改做碳酸，而不是把清水广告印到舱上。

### 第 0 步 · 纸面和安全

- 氢按可燃气：泄漏检查、阻火器、静电接地。
- 问工程师：客用时会不会同时装氢和臭氧。会，则互锁必须是硬件，不能只靠软件。
- 供应商出材质和过流件清单。

### 第 1 步 · 水桶小循环（不上人，不上舱）

1. **盐析。** 同样气量、同样压力，测 10 / 20 / 30 分钟溶解氢、溶解氧、pH（碳酸）。  
   建议放行：高盐溶解氢 ≥ 同条件清水的 40%，且绝对值 ≥0.3 ppm。达不到就不要做氢浴产品。
2. **泡径。** 外包测 D50。高盐若把超微细全并成大气泡，氢锁不住。
3. **衰减。** 停气后 0 / 10 / 20 / 40 分钟再测溶解氢。决定体验中要不要一直补气。
4. **头空间。** 带盖水桶模拟小头顶空间。排风开 / 关对照。  
   否决：排风正常时氢仍接近 1%，或排风停 5 分钟内到 2%。这种架构不许上船。

### 第 2 步 · 接到储液罐或空舱（仍不上客）

5. 故意先开臭氧再请求开氢，必须拒动。
6. 高盐连续循环 4 小时：看压差、泵是否气蚀、喷嘴是否结晶。
7. 开泡前后测紫外透过、水下声压。差太大就改 SOP（体验时关声振或加长消杀）。
8. 停气之后溶解氢还在降、头顶氢还在升的那段时间，排风必须继续。记下要多排几分钟。

### 第 3 步 · 有人（前面全过之后）

禁忌按现有门店清单。不宣称治疗。人数不必多，但必须 **同一人、同一舱、开 vs 关**。

| 看什么 | 工具 | 用来回答 |
|---|---|---|
| 溶氢 / pH 是否到目标 | 仪 | 功能有没有做上 |
| 头空间有没有越线 | 仪 | 能不能卖 |
| 皮温、发红、白雾 | 红外 / 照片 | 碳酸有没有体感 |
| 滑、暖、放松打分 | 纸 | 相对关泡有没有增量 |
| 气促、头晕、要出舱 | 现有红旗 | 一出现就停项目 |
| 经皮气体、心率变异 | 仅科研合作 | 不进控制器，不进广告 |

**做到设备上了，看这五条：**

1. 控制器能选「氢浴 / 碳酸 / 关」，互斥是真的。  
2. 高盐氢浴 20 分钟，液相氢过台架放行线，头空间氢 < 1%。  
3. 碳酸模式有可见贴肤微泡，或皮温可重复升高；头空间二氧化碳 < 0.5%。  
4. 当天消杀仍能按 SOP 做完（或 SOP 已经改过）。  
5. 铭牌数字来自本机报告，不是日本官网。

**对使用者有效，看这三层：**

- 工程有效：上面五条。  
- 体验有效：开关对照下打分或皮温有差别。  
- 医疗有效：本方案不做这个结论。要做另立课题、走伦理。

## 8. 落地节奏（不要一次上三种气）

| 阶段 | 做什么 | 输出 |
|---|---|---|
| P0 台架 | 买分路 PEM、混合器、溶氢仪、头空间三气传感器；清水 vs 高盐水桶 | 盐析报告。决定做不做氢 |
| P1 安全 | 高盐小循环 + 头空间否决实验 | 过 / 不过。不过则氢浴停，只评估碳酸 |
| P2 空舱 | 旁路接到储液或空舱；互锁、结晶、声、紫外 | 改装图、SOP 草稿 |
| P3 体验 | 小样本开关对照 | 铭牌数字、对客话术白名单 |
| P4 选配 | 先上氢浴 **或** 先上碳酸，不要同日双开 | 服务菜单 |

氧浴放到 P4 以后。氢氧吸入如果要做，做成出舱独立设备。

对客一句话（P3 过关之后才许说）：

「这台舱可以选配氢浴或碳酸微泡。液体里的浓度以本机铭牌为准。不是治疗设备。」

## 9. 和现有宣传口径怎么对齐

| 现在材料里的说法 | 研发上怎么处理 |
|---|---|
| 纳米水溶氢、万级 ppm | 不作工程目标。铭牌用本机测到的 ppm / ppb |
