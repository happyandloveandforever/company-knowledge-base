# 罗森堡腹侧检验 + 治疗动作：自学流程

> 根据史丹利·罗森堡《迷走神经的自我检测与治愈》整理成自学用文本。检验来自第4–5章观察法；治疗动作是第二部「恢复社会性参与」的入门三套（基本动作、火蜥蜴、扭转），用自己的话写成步骤，不是逐页抄书，也不是漂浮门店 SOP，更不是医疗诊断。
>
> 你在做的不是「修好迷走神经」，而是：**让社会性参与这一档（腹侧）有机会回到线上，并用同一套检验看有没有动。**

---

## 0. 铁律（检验和动作共用）

1. **先测 → 再做 → 再用同一套再测。** 不测就做，容易把关机当成放松。
2. 动作是给神经**信号**，不是健身房拉筋。不追求更痛、更大角度、更久。
3. 有效的信号常常是：不自觉的**吞咽、哈欠、叹气、眼泪、脸或肚子突然暖和一点**。等到其中一件出现，就可以回来。等不到也不要硬撑超过约 90 秒。
4. 一次只做**一侧**，做完回中间停几息，再做另一侧。不要左右甩着赶进度。
5. 头晕、恶心、视物旋转、胸痛、呼吸困难、手臂发麻、突然最痛头痛、外伤后颈痛：**立刻停，躺下或坐下，走医疗。**
6. 不要扳颈椎、不要让别人按着头猛转、不要用力掐、不要压舌探喉。
7. 处方药的增减只问开药医生。这些动作不是停药方案，也不治疗 COPD、疝、自闭、偏头痛、POTS。
8. 儿童、孕妇、颈椎病/骨质疏松/抗凝、刚做过腹部或颈部手术：只做检验 B/C/D；动作要么跳过，要么先问医生。

---

## 总流程（一次完整自学，约 20–25 分钟）

```
① 准备，坐 1 分钟
② 检验 A–F（必做）G（选做）          ← 约 10 分钟，见下文「一、检验」
③ 看记录，决定今天做哪一个动作：
     - 几乎每次都从「基本动作」开始
     - 转头明显不对称、肩一边塌 → 基本动作后再做「火蜥蜴」
     - 站着含胸、头前探、肩带一边死一边垮 → 再加「扭转」（仍是信号，不是瑜伽扭转比赛）
④ 做动作（每侧等到吞咽/哈欠/叹气，或满 60–90 秒）
⑤ 用同一套检验再测 A、C、D、F     ← 只要 3–4 分钟
⑥ 记：哪一项有动。没有动也不加码，明天再来
```

理想的「做完」不是更想睡死，而是：**更平静、仍清醒、更能对视、声音有一点起伏、转头松一点。**

# 一、检验（量尺）

## 1. 准备

1. 有靠背的椅子，双脚着地，不翘腿。
2. 光线稳定。手机静音。一面镜子（或前置摄像头但不拍照）。
3. 坐 1 分钟，只问：哪里最紧？气到锁骨还是到下肋？现在像能说话，还是想躲？

## 2. 检验顺序

**A 整体扫一眼（30 秒）**

| 更像哪一档 | 脸和眼睛 | 声音 | 呼吸 | 身体 |
|---|---|---|---|---|
| 腹侧 / 社交 | 中脸有流动，能对视 | 有韵律 | 下肋能动 | 不紧不塌 |
| 交感 / 动员 | 瞪、较劲 | 快、抢话 | 上胸、锁骨 | 肩颌紧 |
| 恐惧冻结 | 躲目光 | 发紧或突然小 | 吸到上胸就憋 | 像暂停 |
| 背侧 / 关机 | 脸平、头低 | 平、开口先叹气 | 几乎看不见 | 软、沉、慢 |

**B 中脸（1 分钟）**  
面对镜子不故意做表情 20–30 秒。看下眼睑到上唇有没有自己冒出来的微动。对视 2–3 秒是否轻松。再挤一个假笑对照：只有嘴在笑、眼嘴之间是死的，先当防卫没解除。

**C 发短促的「啊」（1 分钟）**  
张嘴，舌头躺着，不要伸手进嘴里。发短促「啊、啊、啊」三到五下，**不要拖长**。看悬雍垂是否中线、两边软腭弓是否对称快提。一侧不动就记「左弱/右弱」，不是诊断。

**D 下肋呼吸（1 分钟）**  
双手贴左右最低肋骨。用平时的呼吸看 8–10 次：手有没有被推向两侧。只有锁骨在动 = 上胸模式。不要用力鼓肚子。哮喘/慢阻肺/心衰：只看，不练。

**E 吸快呼慢的脉搏（2 分钟）**  
食指中指轻按对侧桡动脉（不要用拇指）。自然吸气看脉搏是否略快，呼气是否略慢。6–8 个周期。完全不变先当弹性不足。不是心电图，也不解释成防癌。

**F 转头约 90 度（1 分钟）**  
坐正，肩不要帮忙，下巴水平，慢慢右转再左转。看角度、哪侧先痛。对侧痛更常先想斜方肌/胸锁乳突肌被拉长；同侧痛先想肩胛提肌。眩晕、颈外伤、骨质疏松：跳过。不要甩头、扳头。

**G 肩带轻比（选做）**  
拇指食指在衣领线、颈肩交界轻轻捏斜方肌上缘 1–2 秒，左右比软硬。锐痛、发麻、术后、抗凝、儿童不配合：不做。

## 3. 记录表

日期：__________  测前 / 测后

| 项 | 结果 |
|---|---|
| A 更像哪档 | 社交 / 动员 / 冻结 / 关机 |
| B 中脸 / 对视 | 流动有无；对视轻松/想逃 |
| C 发「啊」 | 对称 / 左弱 / 右弱 / 看不清 |
| D 下肋 | 双侧 / 上胸 / 左弱 / 右弱 |
| E 吸快呼慢 | 明显 / 勉强 / 不变 |
| F 转头 | 右__ / 左__ ；痛：同侧/对侧/无 |
| G 肩（选做） | 左硬 / 右硬 / 差不多 / 未做 |
| 现在能不能说话 | 能 / 勉强 / 不想 |

# 二、治疗动作（入门三套）

原则：慢、小、等信号。一侧做完必须回中间。

出现这些就**结束这一侧、回中间**：吞咽、哈欠、叹气、不自觉流泪、脸上或胸口突然暖、肚子咕一声、肩自己掉下来。  
出现这些就**整次停止**：晕、吐意、耳朵轰鸣加重、手脚发麻、心慌、视线发黑。

---

## 动作 1：基本动作（每次都先做这个）

这是作者诊所里「测完先做」的那一个。目的是让眼、头、颈这一组社会性参与神经重新协调，不是拉伸脖子。

### 坐姿版（最方便自学）

1. 坐稳，背可以靠椅，双脚着地。骨盆不要歪向一边。
2. 十指交叉，托在后脑勺（不是脖子正中）。手只是摇篮，头的重量交给手，肘自然打开，不要夹头。
3. 眼睛平视前方，吸一口气，呼气时把眼睛**慢慢转到右侧**，像看自己的右耳方向。头可以跟着眼睛**稍微**转一点，但肩和肘不要跟着转。
4. 停在第一个「还能轻松喘气」的位置。不要转到痛。
5. **等。** 默数呼吸。通常 20–60 秒。等吞咽、哈欠或叹气。等到了，在该侧再停 1–2 息。
6. 眼睛和头一起慢慢回正中。双手仍托着头。休息 3 次呼吸。
7. 同样做左侧。
8. 放下手，坐 20 秒，立刻做检验 C（发「啊」）和 F（转头）看有没有变。

### 仰卧版（更稳，适合坐姿容易耸肩的人）

1. 躺平，膝盖可弯，脚着地。腰不要故意压平。
2. 十指交叉托后脑，肘向外摊在床面或地板上。
3. 眼睛看天花板 → 慢慢看向右 → 等信号 → 回中间 → 再看向左。
4. 肩始终沉在地面。若肩要跟着眼睛跑，幅度再减小。
5. 做完不要立刻跳起来。侧身坐起，再站。

### 这一套怎么选边（可选，不是必须）

若检验 C 或 F 明显一侧弱：可以**先做弱的那一侧**，再做另一侧，仍各做一轮即可。不要在弱侧反复加码。

### 基本动作的常见错误

- 把眼睛甩到极限，下巴扬起（变成压颈椎）。
- 屏息死撑 3 分钟。
- 左右连续甩，中间不休息。
- 做完立刻判断「我治愈了」。只看再测有没有动。

## 动作 2：火蜥蜴（转头仍不对称时再加）

蜥蜴侧向看的时候，头是**侧屈**（耳朵靠近肩膀），不是把下巴转到肩上。作者用它恢复转头和第十一对脑神经的协调。先会基本动作，再学这个。

### 坐姿版（推荐先练这个）

1. 坐稳，双手放大腿，肩放下。
2. 眼睛平视。把**右耳慢慢靠近右肩**。脸仍朝前，不要把鼻子转向右肩。像用头去听右边口袋。
3. 停在不痛的位置。右肩不要耸上来接耳朵；是头侧过去，肩留在原地。
4. 保持这个侧屈，把眼睛慢慢向上看（看右上方的天花板角）。头不要再加幅度。
5. 等吞咽、哈欠或叹气。或满 45–60 秒。
6. 眼睛回正，头慢慢立直。休息 3 息。
7. 左侧同样：左耳近左肩，眼睛看左上。
8. 再测检验 F（转头）。

### 四点跪姿版（坐姿已经轻松之后才试）

1. 双手双膝着地，膝在髋下，手在肩下。头自然垂成中立，不要塌腰也不要弓成猫。
2. 慢慢把右耳带向右肩（侧屈），同时眼睛看向右侧上方，脊柱像一条鱼在水里轻轻侧弯。幅度小。
3. 等信号或 30–45 秒。回中立。换左。
4. 膝盖痛、手腕痛、怀孕后期：不要跪，只用坐姿。

### 火蜥蜴的常见错误

- 做成「看自己腋窝」的旋转，而不是侧屈。
- 肩膀去接耳朵。
- 在痛的落枕上硬做。落枕急性期只做基本动作，或停。

---

## 动作 3：扭转（给肩带神经信号，不是瑜伽扭转）

站立以后斜方肌既要稳头又要稳肩。作者的扭转是让头和胸廓暂时「分开干活」，把信号送给这一组，不是比谁转得更开。

1. 坐在椅前 1/3，双脚与髋同宽，踩实。
2. 头保持朝向正前方，像鼻尖钉在对面墙上。
3. 右手轻扶椅面或大腿。呼气时，把**胸口（不是头）**慢慢转向右，大约 20–40 度就够。左肩可以略向前，右肩略向后。
4. 头仍朝前。你会觉得颈根和肩带在轻轻分开。停在不痛处。
5. 等吞咽、哈欠或叹气。满 45–60 秒也可以回来。
6. 胸口转回正对前方。休息 3 息。
7. 反侧：头仍朝前，胸口转向左。
8. 再测检验 A（姿势/含胸）和 G（肩带，若你做了）。

### 进阶一点点（可选）

若头朝前、胸转向右已经很轻松：允许眼睛跟着胸口看向右，**头仍尽量少转**。仍不是把颈椎拧到极限。

### 扭转的常见错误

- 头和胸一起猛转（变成普通看后面）。
- 用手臂把膝压住、把腰拧到弹响。
- 当开舱前热身操带着客人做。

## 三套怎么排队（按检验结果）

| 今天的检验 | 做 |
|---|---|
| 第一次自学 / 脸平、发「啊」不对称、人发紧或发飘 | 只做基本动作一轮（左右各一次） |
| 基本动作后再测，转头仍差一截 | 同一天可加火蜥蜴一轮；或隔天再加 |
| 头能转了，但含胸、头前探、肩一边垮 | 基本动作后加扭转一轮 |
| 再测已经更接近社交档 | **停。** 当天不要为了「再好一点」叠第四套 |
| 做完更晕、更空、更不想说话 | 停止动作，只坐着感受脚。下次减幅度、只做坐姿基本动作 |

建议频率：每天 1 次，或隔天 1 次。不要一天做五轮。作者强调的是**重复的小信号**，不是剂量竞赛。

---

## 做完立刻再测（必做，3 分钟）

只重复这四项，和测前用同一把尺：

1. C 发「啊」：两侧有没有对称一点
2. D 下肋：有没有打开一点
3. F 转头：弱的那侧有没有容易一点
4. A 能不能对视、说话有没有一点音调

记下「有动 / 没动」。没动 → 明天仍从基本动作来，不要自己加扳法。

---

## 明确不教、也不要自己发明的

- 腹内脏往下拉胃、深压肚子（锐痛必须停；本手册不纳入）
- 给别人大力捏斜方肌当治疗
- 枕下猛按、承诺改善椎动脉/偏头痛
- 四分钟拉皮的完整手法（那是书里另一节；先把上面三套做熟）
- 用「三十秒、百分百、肺活量 70%→102%」当自己的疗效标准
