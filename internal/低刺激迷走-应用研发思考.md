# 低刺激 × 迷走激活：应用研发思考

内部工作底稿｜2026-09-05｜**不写专利，只谈产品和工程**

> 读者：研发、工程、运营、产品。  
> 目的：把知识库（设备参数、REST、迷走机制）和专利库（先案、已打掉方向、低刺激工程）交叉成**能落地的技术水平提升路径**。  
> 红线：不写治疗、不写适应症、不把器械 VNS 获批当成漂浮证据。对外仍用 CIS / VGMECH / SOP。本文件与 `KP-RD-*` 仅内训。

## 0. 一句话结论

**技术水平往上走的主方向，不是再往舱里塞模块，而是：先把环境本底测出来并压到人能感觉到的阈值以下，再让四条间接迷走通路自己工作；舱外用共振呼吸，把「做一次很放松」变成可训练的自主神经能力。**

低刺激不是装饰，也不是「关灯关音乐」这么简单。它是迷走能被环境启动的前提。本底越高，你越得加大振动、灯光、气体去「压过」它——结果本底更高，人更不容易进入副交感。

这条原则来自两库交叉，不是新口号：

| 来源 | 它已经说清楚的 |
|---|---|
| `KP-WEB-007` / `KP-VGMECH-005` | Flotation-REST = 尽量关掉九条感觉通道 |
| `KP-VGMECH-007`～`011` | 迷走走**环境间接**四条通路，不是电刺激神经 |
| `KP-CHAMP-008` vs `KP-CHAMP-006/009/010` | 宣传上「刺激归零」，配置上又叠振动、舒曼波、脑波发射 |
| 专利库总图（给人看的工程菜单） | 低刺激是让目标信号用极小功率起作用的前提；本底上升时先降本底，不要加大功率 |
| 已打掉方向 | 40Hz、掩蔽声、舱内触觉换能器当卖点、把 SPA 彩光/气泡/混气直接搬进舱 |

## 1. 我们现在真正握在手里的底座

先认现有机型，后面所有升级都挂在这上面，不另起炉灶。

### 1.1 硬件骨架（以铭牌/合同为准）

三分体：舱体 + 智能主机 + 独立储液。占用时液体可抽回储液罐，人在空舱起身。这点对「老年在盐液里坐不起来」这类问题已经改变了产品前提，不要再按「人一直泡在满舱里起身」做机构。

| 机型 | 材料口径（未锁，以铭牌为准） |
|---|---|
| FA-D | 舱 2350×1400×1400 mm；总液 500 L / 有效 400 L；额定约 3.0 kW；运行约 800 kg |
| FA-O | 舱 3000×1800×1600 mm；水箱 800 L；进出水 DN40；舱体功率材料写 ≤100 W |
| 液 | 硫酸镁体系，手册比重 1.24–1.27；SOP 开舱验收 1.23–1.26 |
| 温 | SOP 验收 36±0.5℃；话术和部分诊疗稿写 38℃；消杀一处写 36.5–39.5℃——**三套数未锁** |
| 消杀 | 排空 → 过滤 → 臭氧/紫外/光触媒 → 无菌储液；材料称 15 分钟三翻转 3-log；池型批次间内循环 ≥1 小时。两口径不可互换 |
| 房间 | 功率约 3000 W / 16A 独立地；室温材料写 ≥26℃；紧邻淋浴；舱盖可直接推开；呼叫器在舱 |

对接：`KP-CHAMP-014`～`018`、`021`，`KP-SOP-015`、`022`，`KP-MAN-002`、`006`。

### 1.2 迷走：我们卖的是环境，不是刺激器

四条并行通路（`KP-VGMECH-007`）：

1. **感觉输入减少** → 中枢降噪，交感高警戒回落  
2. **近失重卸载** → 肌梭/本体/疼痛传入下降  
3. **呼吸自然减缓** → RSA 增强 → 高频 HRV 上升（目前最可信的「启动」间接指标）  
4. **HPA 负荷减轻** → 皮质醇等线索，是 1～3 的下游，不是单独可拧的旋钮

行业地图位置（`KP-VNSMAP-006`）：植入式 / 耳支 taVNS / 颈支 tcVNS 是别人的器械；慢呼吸、冥想、耐力、冷暴露是可训练行为。漂浮的差异化是**一次就能进入低刺激的多通路环境**，不是等效 FDA 刺激器。

### 1.3 综合干预怎么分层（不要一锅炖）

CIS 三层（`KP-CIS-003`）在应用上要拆开时间和空间：

| 层 | 模块 | 放哪 |
|---|---|---|
| 神经调节 | 方舟 + 共振呼吸 + 冷热 | **舱内只做方舟 REST**；呼吸在舱前/舱中极轻引导/居家；冷热在**另一工位** |
| 细胞能量 | 氢、PBM、镁营养 | **会话前或后**，不要和深度 REST 同时抢通道（光、气、热都是刺激） |
| 系统恢复 | 睡眠、肠脑、疗程、HRV 复评 | 舱外疗程，不是舱内功能 |

## 2. 最大的技术水平缺口：我们在跟自己打架

冠军系列同时写了两句（`KP-CHAMP-008` vs `006/009/010/011`）：

- 「外源刺激尽可能归零」  
- 深度放松时可叠加：液体振动、7.83 Hz 舒曼波、单通道 EEG 后「发射平静脑波」、音乐/光疗、负氧离子、碳氧气、纳米氢、红外/磁疗……

REST 的操作定义是关掉视觉、听觉、嗅觉、味觉、温度、触觉、前庭、重力、本体感觉（`KP-WEB-007`）。**每加一个「功效模块」，就在重新打开至少一条通道。**

行业里也有人走这条叠加路：用掩蔽声盖住泵声、舱内装触觉换能器当大扬声器。那是**提高刺激总量**，和「最低环境刺激」方向相反。我们若继续堆，会在体验上变成「功能很多的浴缸」，在迷走上反而变差。

**研发决策：默认程序 = 深度 REST（九通道尽量关）。一切叠加都是可选、可关、且必须证明它不抬本底。** 证明不了，就放到舱外工位。

## 3. 九条通道：现在可能从哪漏

不必一次做成实验室。先按「客人投诉/出舱过早/后半程睡不着」对照。数字未测的标「待测」，不要用宣传句代替测量。

| 通道 | 深度 REST 目标 | 现产品上的典型泄漏 | 应用层改法 |
|---|---|---|---|
| 视觉 | 暗适应后仍低于可感知阈值 | 指示灯、门缝、手机/Pad 多屏（监护端漏光）、会话后半程人眼变灵敏 | 占用可见光硬件断电；监护改近红外；漏光做遮挡；「够黑」要随时间变严 |
| 听觉 | 耳位气路+液路都静 | 泵阀、结构传声、液体振动的可闻失真、接待区音乐、掩蔽音选项 | 占用停泵；结构隔振（已有行业做法，继续做）；不要放白噪音；振动若开必须互调不进可闻区 |
| 嗅觉 | 无氧化剂味、无香氛 | SOP 雪松香氛；臭氧若占用期残留 | 舱内不放香；占用前气腔残余臭氧达标才开门；香氛留在接待区 |
| 味觉 | 少盐雾到唇 | 液面飞溅、头位过低 | 头枕只定位不承重；液位与头位校准（SOP 已有耳入水、口鼻离水） |
| 温度 | 液面上下净热流趋零 | 液 36℃ vs 气腔随房间 ≥26℃；露出的胸腹/脸蒸发散热 | 气腔温湿度跟液温，按盐液水活度设露点，不是把气温设成等于水温就完 |
| 触觉 | 无接触面、无回波拍身 | 头枕接触、耳塞（SOP 必戴）、自激液面波、气流 | 评估「不戴耳塞能否靠液气静音」；消波或调度泵到人动的时候 |
| 前庭 | 无持续晃 | 液面反射波、注液/循环余流 | 占用零流速；波吸收或被动边角消能 |
| 重力 | 密度落在仰浮窗口 | SOP 1.23–1.26 vs 液 1.24–1.27；蒸发导致漂移 | 开舱验收锁窗；气腔湿度稳住蒸发，密度才稳 |
| 本体 | 近失重、无支撑反力 | 头枕若承重、底板/扶手在占用态侵入 | 占用态所有支撑退出漂浮空间（离舱再给反力面） |

耳塞是妥协：它挡气路噪声，但本身是触觉和本体刺激，还改变「半浸耳」这条漂浮特有的声学处境。中期目标应是**气路足够静，耳塞变成选项而不是必戴**。

## 4. 四条迷走通路，分别提高什么技术水平

不要发明第五条「电刺激迷走」。应用层只加固这四条。

### 4.1 通路一：中枢降噪 = 九通道本底

这是主战场。技术水平的第一指标不是「模块数量」，是**五个可测残余量**：

1. 耳位声压谱（气路 + 能测到的液路）  
2. 眼位残余亮度（按暗适应时间滑动上限）  
3. 液面净热流或液上/液下温差  
4. 液面残余波高  
5. 气腔氧化剂/气味代理（臭氧等）

任一超阈，就不许宣称「深度模式」，系统降到浅模式（留缝、可开盖、灯有下限）——这和青少年/老年「非全 REST」封套是同一套状态机，不是两套产品。

### 4.2 通路二：卸载 = 密度窗口 + 真的不碰舱

浮力窗口是硬约束。声、热、氢气泡如果扰动密度或产生浮力差，会让人「漂不稳」，本体和前庭马上醒。  
应用含义：含气液、射流、循环，在占用期默认全关。要溶氢/溶氧，放到注液前完成并消泡，占用时液体尽量无气泡。

### 4.3 通路三：呼吸 / HF-HRV = 最高性价比

文献侧：约 4.5–6 次/分（约 0.1 Hz）时 HRV 常出现峰值；多数健康成人可先用 6 次/分，不必人人测个体频率（`KP-VGMECH-019`～`022`）。

产品协议（已经写过，欠的是做成默认服务而不是选配话术）：

- 进舱前 5 分钟腹式鼻呼吸  
- 舱内：默认不放音乐；若要引导，只用**刚能听见的呼吸节拍**，引导 5～10 分钟后淡出到静音  
- 疗程间隙：居家 10–20 分钟/天，4 周

**不要把产品振动的 0.1 Hz 和呼吸的 0.1 Hz 说成一回事。** 一个是人自己的呼吸，一个是外部振动叙事。混在一起，研发会去做「用振动代替呼吸训练」——既贵，又重新打开触觉通道。

监测：出舱 HRV 只讲弹性、只做前后对比（`KP-SOP-018`）。不要用毫米波穿高盐液测心率——物理上穿不透。若要做非接触调度，优先看**腔压微波动 / 液面微起伏**（中性浮力下心冲击和呼吸排水更明显），用途是「人是否还在安静地漂、何时可以启动有噪声的动作」，不是医疗诊断。

### 4.4 通路四：HPA = 不要当旋钮拧

皮质醇下降是漂浮文献里的线索，不是舱内可闭环的控制量。把它当结果观察（唾液、问卷）可以；当「发射某种波来降皮质醇」不可以。会话后 30 分钟静默（SOP 已有蜂蜜水静默）比再加一个舱内模块更接近这条通路。

## 5. 应用架构：三层时间，不要六模块同时在舱里

```
[会话前 5–15 min]   共振呼吸；可选局部红光 / 氢水 —— 在舱外
[占用 45–90 min]    深度 REST：九通道关；泵阀加热循环全停或极静
                    唯一允许的「信号」：可选极低音量呼吸节拍，然后淡出
[占用结束]          灯、支撑、冲洗到温，再开锁（老年/前庭不稳）
[会话后]            静默 20–30 min；HRV 对比；PBM / 氢 / 冷热在另一工位
[两次之间]          排空、壁面消杀、过滤、密度温度氧化剂进窗，才叫就绪
```

**冷热交替训练的是自主神经弹性，和 REST 的「最低刺激」是反相操作，绝不要做进同一舱同一时段。** 那是 CIS E 的另一张床/另一间房。

氢、光、营养仍然有价值，但它们服务的是细胞能量层。在占用态开氢气泡、开 660/850、开碳氧气，等于用通路一的损失去换通路二/三不一定存在的增益。

## 6. 不改结构也能做的（先做，成本最低）

1. **默认场景改名并改行为**：「深度 REST」= 灯 0、声 0、振动 0、香 0、气 0。冠军系列叠加全部降为「浅模式 / 体验模式」，进深度模式必须一键全关。  
2. **占用态静默联锁**：门到位且占用为真 → 循环泵、臭氧、紫外、光触媒激发、注排液全部禁止。不是软件提示，是做不到。空舱才消杀。  
3. **舱内停用香氛**；雪松留接待区。嗅觉通道现在是自己加的。  
4. **锁一个水温**再改手册。在未锁前，运维执行 SOP 36±0.5℃，对客只说「皮肤温恒温」，不要同时报 38。热通道的研发需要一个稳定设定点。  
5. **接待区音乐 ≤35 dB、禁歌词**（SOP 已写）落到隔墙和门缝——这是听觉本底的一部分。  
6. **监护屏不要朝门缝**；舱内取消常亮状态灯。  
7. **把共振呼吸做成每例必做的 5 分钟**，不要等「抗焦虑配置」才出现。  
8. **青少年 / 幽闭 / 老年默认浅模式**：灯声有下限、门不全锁、监护回路闭合。这是安全和应用，不是营销彩灯。

这八条做完，迷走通路一和三会立刻比再买一个频率模块更明显。

## 7. 值得投入的硬件与控制（按性价比）

下面按「先测、再控、再加执行器」排。没有本底数据就上主动对消，会做成新的噪声源。

### P0 · 本底仪表化（两周能出第一张表）

空舱 + 有人占用（或用人形热源+模拟头）测第三节那五个量。至少三种状态：全关、现网默认程序、冠军叠加全开。  
**交付物：一张「本底三态表」。** 这张表决定后面所有投资。没有它，研发在凭感觉打架。

### P1 · 占用 / 空舱 / 就绪 三态机

你们已经有排空式架构，这是相对「液始终在舱里」的竞品的真正优势。应用上要咬死：

- 占用：静、暗、热流闭环、零循环  
- 空舱：气相光催化 + 臭氧打壁面生物膜（液相 AOP 够不着舱壁；高盐还会清掉羟基自由基）  
- 就绪：密度、温度、液相氧化剂、气腔臭氧、（若原料含溴则）溴酸盐，五项进窗才开门

溴酸盐：泻盐含痕量溴 + 液相臭氧是泳池已知路径。先测原料溴本底和旧液累积。测不到溴就不要改工艺；测到了，臭氧只走空舱气相、不进工作液——这是卫生质量，也是嗅觉/化学通道。

### P2 · 液面热中性

这是客人能用语言投诉的痛点（「胸口一条冷线」）。控制目标不是气温=水温，是液面净热流≈0；湿度按当前盐浓度的水活度算。顺带抑制蒸发，密度更稳。限制定向气流，避免新的触觉。

### P3 · 暗适应时间表

固定「全黑」会在第 30～40 分钟失效：人眼阈值下降几个数量级。把允许的残余亮度写成随时间下降的上限，越界就关剩下的指示灯或降出深度模式。近红外监护：可见光通道占用时物理断电。

### P4 · 听觉：先被动，再考虑双通道对消

继续做房间隔振、舱体不碰墙、泵远置（三分体已经提供物理隔离，检查安装是否真的远）。  
若本底表显示占用期仍有稳定低频结构声，再做**气路+液路两套对消**——漂浮时耳在液面，空气扬声器打不到经液体传来的那一截。误差点必须跟着头，不能钉在舱壁（钉在舱壁可能在耳位增噪）。任何要人戴耳机/贴麦的方案都与低刺激冲突。

### P5 · 触觉：回波

人一动，波撞壁弹回。小舱里被动吸波没空间。若主观测试「回波明显」，再做主动吸收边界或端部射流；控制律按高盐密度粘度标定。若多数人感觉不到，降级，别为它开新噪声源。

### P6 · 振动（如果还要保留）

承认「舱里装换能器」已经是行业在售做法，我们的差异不在「有没有振子」。应用纪律：

- 深度 REST 默认关  
- 浅模式若开：一个目标通道，功率由当时本底反算，本底差就先降本底  
- 不做 40 Hz，不做「发射平静脑波」，不做 7.83 Hz 必须开  
- 多频同开时，互调产物不得进可闻区  
- 液体浓度优先保证浮力窗口；不要为了「声耦合更好」把人漂到不稳

### P7 · 非接触「还在安静地漂吗」

用腔压和液面起伏看呼吸相位和体动，把补液、调温、消波这些必然有动静的动作，排到人已经在动或呼吸噪声较大的几秒里。安全动作（急停、开门）不受这个窗限制。  
用途是调度，不是把漂浮舱做成诊断仪。

## 8. 明确不要做（省钱、也避免把迷走做坏）

| 不要 | 原因（应用，不只是法律） |
|---|---|
| 40 Hz 光/声/触振清蛋白、抗认知症 | 别人的神经科学与器械线；会重新打开视觉/听觉/触觉；监管话术危险 |
| 掩蔽声 / 白噪音盖泵声 | 刺激总量上升，与目标相反 |
| 占用时开彩光、PBM、石墨烯远红外 | 视觉+热通道；PBM 放到舱外工位 |
| 占用时打氧/氢/二氧化碳气泡或碳氧气 | 气、嗅、触、密度全扰；密闭舱气体还有安全问题。气体种类本身也不构成技术壁垒 |
| 单通道 EEG 电极 +「发射脑波」当深度 REST | 接触刺激 + 认知任务，和降噪相反；浅模式研究可以，默认程序不行 |
| 经皮氢 / 透皮镁当迷走机制 | 主通路是 REST 卸载；氢走细胞能量层，镁走营养，别写进「激活迷走」 |
| 毫米波穿盐测 HRV | 高盐对这频段近乎不透明 |
| 把冷热、律动床、音疗做进同一占用时段 | 与 REST 反相；音疗/舱内换能器已是红海 |
| 用宣传数字（90% 睡着、58% 焦虑）当研发 KPI | 未锁口径；研发 KPI 用本底表和 HF-HRV 前后对比 |

专利库里打掉的条目，在应用上多数也是「做了也没有独占、还可能把 REST 做脏」。本文件不展开权要，只借它们当**研发黑名单**。

## 9. 90 天内建议实际干的事

不按日历承诺，按任务依赖。工程师签字前，所有阈值都是「待测」。

**第一批（不出新零件）**

1. 默认程序改为深度 REST 全关；叠加进浅模式菜单  
2. 占用—空舱电气联锁检查：人在时臭氧/紫外/激发/循环是否真能被打开（打开就是缺陷）  
3. 本底三态表（声/光/热/波/气味）  
4. 共振呼吸 5 分钟纳入每例 SOP，出舱继续静默  
5. 锁水温口径的决策稿给老板（只决策，不发明）

**第二批（小改）**

6. 可见指示灯遮挡或改近红外监护样件  
7. 气腔温湿度跟随液温的试验（先开环记录，再闭环）  
8. 原料盐溴本底 + 旧液溴酸盐抽检，决定臭氧是否退出液相  
9. 不戴耳塞 vs 戴耳塞的主观+耳位声压对照（决定耳塞能否从必戴改建议）

**第三批（有数据再立项）**

10. 若低频结构声仍在：泵更远置 / 液气双通道对消样件  
11. 若回波投诉真实：端部吸收边界样件  
12. 腔压/液面起伏是否能稳定看到呼吸节拍 → 才做动作掩蔽窗  
13. 浅模式保留哪**一个**可选信号（呼吸节拍 XOR 极低功率振动，不要两个一起）由三态表和主观评分决定

**验收（技术水平升没升，看这些，不看模块清单）**

- 深度模式：五通道残余低于当次阈值的比例  
- 前 10 分钟按铃出舱率（幽闭和热/声泄漏的综合指标）  
- 会话完成率；后半程「总觉得有点亮/有点响/有条冷线」的结构化问答  
- 出舱 HF-HRV / RMSSD 相对进舱前的变化（间接、个体差异大，只做组内前后，不当疗效）  
- 两次之间就绪：五项化学量一次通过率（卫生也是化学通道）

不要用「90% 首次睡着」当验收。睡着可能是热了、闷了、或音乐诱睡，和迷走张力不是同一件事。

## 11. 给非工程同事的摘要

- 迷走在漂浮里不是「打一束波到神经上」，是把外界账单关掉，身体自己换到修复档。  
- 现在最大的提升空间：少做，测干净，默认全静。  
- 最便宜的迷走训练：每次漂之前做 5 分钟慢呼吸，回家接着做。  
- 氢、光、冷热仍然有用，但请放到舱外，不要和「最低刺激」抢同一小时。  
- 专利库告诉我们：很多「听起来很科技」的模块别人已经在卖，再堆既不稀缺，还可能把环境做吵。
